## P1：四轮运动与里程计

- [ ] 用同一个安全组合运动入口完成三项低速测试：前进、左横移、逆时针旋转；每项只确认
  方向、四轮编码器符号和停车，不再做 `MOTOR-005` 这类重复逐轮复测。
- [ ] 精确测量四轮输出轴每圈编码计数；可用每轮连续 10 圈一次完成，不要求堆叠实验。
- [ ] 将 `carcar_hardware` 的四个轮关节接入标准 `velocity` 状态/命令，并使用
  `mecanum_drive_controller`，轮位映射为 M1/M3/M4/M2。
- [ ] 地面只做直行 1 m、横移 1 m、旋转 360° 三项标定；达到导航所需误差后停止调参。
- [ ] 先使用纯四轮反馈完成里程计和唯一 `odom -> base_footprint`，验收前进、横移、
  旋转和静止漂移；此阶段 IMU 只发布和观察，不参与融合。

## P1.5：IMU 后置评估（不阻塞首次导航）

- [ ] 水平静止数十秒，采集 `angular_velocity.z` 并计算均值和标准差，分别记录零偏与噪声。
- [ ] 按 X 前、Y 左、Z 上固定车体坐标，人工逆时针旋转小车；必须观察到
  `angular_velocity.z > 0`。不满足时先修驱动轴映射或 `imu_link` 安装 TF，不改 EKF 参数。
- [ ] 水平静止检查 `ax≈0`、`ay≈0`、`az≈+9.81 m/s²`。当前仅有
  `|a|≈9.174 m/s²`，因此加速度标定尚未通过。
- [ ] 上述检查通过且纯轮式里程计、基础导航稳定后，建立第一版 `robot_localization`
  配置：只融合四轮里程计与经过零偏、单位、坐标轴和符号校正的 `gyro_z`；关闭 IMU
  姿态、全部线加速度和磁力计输入。
- [ ] 二维地面导航默认不融合线加速度；只有实测显示明确收益时才单独立项。
- [ ] Madgwick、线加速度和磁力计均作为后置独立实验；每次只增加一种信息源并与上一版
  对比，不一次性全部启用。
