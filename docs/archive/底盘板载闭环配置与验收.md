# 底盘板载闭环配置与验收（MOTOR-007）

最后更新时间：2026-09-07

## 目的与结论

正式底盘改用 Yahboom Rosmaster X3 控制板内置的运动学分配和编码器 PID，
ROS 仅向 `set_car_motion(vx, vy, wz)` 发送车体速度。历史 `set_motor()` 直接
PWM 和 Jetson 侧四轮 PWM PI 仍保留作故障回归，不再作为正式底盘方案。

用户已确认 `15%` 直接 PWM 无法稳定克服整车静摩擦，横移时尤其明显。
这是废弃开环 PWM 作为正式方案的主要理由，不通过盲目提高 PWM 掩盖。

## 原厂约定与当前接线

Yahboom 官方 ROSMASTER X3 资料把电机端口定义为：M1=左前、M2=左后、
M3=右前、M4=右后；官方也明确 `set_motor()` 是不使用编码器测速的 PWM
接口。本项目只引用该接口/接线约定，不复制官方代码或资产。参考仓库
`YahboomTechnology/ROSMASTERX3`，查看时固定提交
`8783d6853e0fec7cdc25e133aea211dc52688d20`；GitHub 仓库页未声明 license，
因此未从中引入受保护实现。

| 控制板端口 | 当前实车已确认 | 板载 X3 闭环所需目标 |
|---|---|---|
| M1 | 左前 | 左前（不动） |
| M2 | 右后 | 左后 |
| M3 | 右前 | 右前（不动） |
| M4 | 左后 | 右后 |

## 接线修正（必须在断电状态完成）

1. 关闭电机主电源并拔掉电池/电机供电，确认四轮无法动作。
2. 给当前 M2 的“右后轮整套电机+编码器插头”和 M4 的“左后轮整套插头”
   分别贴标签。
3. 仅交换 M2 与 M4 的整套插头，使 M2=左后、M4=右后。M1/M3 不动。
4. 本步不单独对调某两根电机线，不重排编码器引脚。如果电机与编码器极性
   被分开改动，板载 PID 可能变成正反馈并突然加速。

交换完成后仍只能先架空验证，不直接落地。若任一轮方向不对、突然高速、
抖动或尖叫，立即断电，只记录现象；不在通电状态拔插，不继续改线试错。

## 软件配置

- 正式 `carcar_base/config/base.yaml` 固定 `drive_mode: board_motion_pid`，速度上限
  在地面标定前为 `0.15 m/s` 和 `0.8 rad/s`，命令看门狗为 `0.3 s`。
- 首次验收使用隔离的 `board_closed_loop_test.launch.py`：限制为 `0.08 m/s`、
  `0.40 rad/s`，不发布 odom TF，不启动雷达、相机、Nav2 或正式 bringup。
- 测试键盘每次只发一个有界短脉冲，之后发送三次零速；驱动节点对
  超过 `0.3 s` 未刷新的命令再次停车，退出时重复发送零速并释放串口。

## 完整构建命令

目的：语法检查新的隔离 launch 和板载闭环驱动，构建 `carcar_base`。
该步不打开串口，不会让电机转动，可在电机断电时执行。预期构建和测试均通过。

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
/usr/bin/python3 -m py_compile \
  src/carcar_base/carcar_base/rosmaster_node.py \
  src/carcar_base/carcar_base/chassis_motion_keyboard.py \
  src/carcar_base/launch/board_closed_loop_test.launch.py
/usr/bin/colcon build --symlink-install --packages-select rosmaster_vendor carcar_base
/usr/bin/colcon test --packages-select carcar_base --event-handlers console_direct+
/usr/bin/colcon test-result --verbose
source install/setup.bash
```

## 首次架空方向验收

硬件前提：M2/M4 整套插头已在断电状态交换；车轮离地并有可靠支撑；
人、电线和松散物远离轮子；电机使用官方要求的 12 V 供电；硬件电源开关
在手边。先关闭所有可能打开 `/dev/myserial` 的节点。

终端 1 目的：独占串口，启动只调用板载 `set_car_motion()` 的受限驱动。
启动时先发三次零速，本终端本身不会主动发送非零动作。预期日志包含
`drive_mode=board_motion_pid`。

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source install/setup.bash
pgrep -af '[r]osmaster_node|[c]ontroller_manager|[f]our_motor_motion_test_node' || true
fuser -v /dev/myserial /dev/ttyUSB0 2>/dev/null || true
ros2 launch carcar_base board_closed_loop_test.launch.py
```

终端 2 目的：发送一次最多 `0.40 s`、`0.05 m/s` 的前进命令，用来判断
四轮方向和板载闭环停车，不标定速度或里程。启动后只按一次 `i`，
不长按，不按数字键。

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 run carcar_base chassis_motion_keyboard --ros-args \
  -p linear_speed:=0.05 \
  -p angular_speed:=0.25 \
  -p pulse_duration:=0.40 \
  -p command_rate:=10.0 \
  -p settle_duration:=0.40
```

预期：按 `i` 后四轮都沿车辆前进的滚动方向转动，约 `0.40 s` 后全部
停止，终端输出四路编码器增量。架空时不要以轮速不完全相同判定 PID 失败。

异常停止：先按空格或 `k` 重复发送零速，然后按 `q`；若仍运动、突然加速、
抖动或键盘无响应，不等软件停车，立即断开电机 12 V 主电源。

## 观察和停止

架空前进方向确认后，另开终端依次观察。这些命令只读 ROS 话题，
不发送速度，不会改参数：

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /chassis_motion_test/diagnostics --once
ros2 topic echo /chassis_motion_test/encoders --once
ros2 topic echo /board_closed_loop_test/wheel/odometry --once
```

停止与恢复：键盘终端按 `q`，launch 终端按 `Ctrl+C`，然后确认串口释放。
如果串口仍被占用，只记录 `fuser` 输出并定位进程，不用 `kill -9` 盲目终止。

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic pub --once /chassis_motion_test/cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.0, y: 0.0}, angular: {z: 0.0}}"
pgrep -af '[r]osmaster_node|[c]hassis_motion_keyboard' || true
fuser -v /dev/myserial /dev/ttyUSB0 2>/dev/null || true
```

## 后续地面验收

只有架空前进方向、编码器反馈和自动停车都通过后，才能把车放到平整地面，
保证前后左右各至少 1 m 无人无物，仍使用上述 `0.40 s` 参数，分别只按一次
`i`、`j`、`u`。三项依次验收前进、左横移和逆时针旋转；每次完全停止后
再做下一项。

本项通过前，不启动 `carcar_bringup robot.launch.py`，不做 1 m/360° 标定，
不调 PID，不写控制板 flash，不接入 Nav2。
