## 现场现象与已确认原因

车辆在操作者认为空旷的场地再次“故障锁停”，恢复提示0/6帧、有效点不足50及“多解竞争”；手动接管后又提示方向扫掠检查超过8毫秒。

日志已区分各层原因：最先停车的是回环校正后的临时人工墙位置待复核，当时定位仍健康；随后“重新检查”误入完整定位恢复。恢复评分先对整圈抽稀、再过滤3米范围，使原本168～175个有效点只剩42～44点。基础评分提前拒绝后没有执行多解搜索，旧页面却显示已经存在竞争车位。手动方向则既有计算超时，也有旧完整几何审查确认的缺束／盲区，不能把这些都解释成碰撞。

本轮已修复有效束选择、检查状态和失败原因；仅墙位待复核时使用已有墙确认入口；手动增加盲区反例快速拒绝和连续有效束保守预裁剪，保持原防撞、盲区、限速和停车条件。详细事实、研究依据和软件边界分别见[实施记录](../2026-11-04-恢复采样与手动扫掠修复.md)与[方案调研](../2026-11-04-恢复采样与手动扫掠修复调研.md)。

## 已完成的软件验证与未验证事项

恢复／手动发布批次完成114项C++、33组真实Chromium及正式页面只读后验；手动历史样本160次重放的最终P99为0.112197毫秒、最大0.178152毫秒。640组固定种子几何对照判定差异为0。它们是该批次的软件结论；后续速度保留补修另有50项最终软件复验通过；两批数量有重叠，不把前批数量当成已经覆盖新补修。

需要继续保持以下判读边界：

- 真实六帧恢复输入的有效点修正已验证，首帧通过实际竞争者搜索；六帧只覆盖约0.483秒，不足原1秒保持时间，不能称整条AMCL／SLAM恢复提交已实车通过。
- 原四次手动手势在给旧算法充分计算时间后仍有盲区；优化应及时解释拒绝。历史扫描下纯后退仅在离线几何检查可行，当前实物后方空间与停车距离仍需现场核验。
- 空旷、地图看起来清楚或残差很小，都不能单独证明各定位方向充分受约束，也不能证明没有远处等价车位。真正退化和多模态需独立证据，不能据通用提示下结论。
- 本轮没有代理实车运动、实物方向确认、定位恢复后的连续探索验收或长时间稳定性验收。
