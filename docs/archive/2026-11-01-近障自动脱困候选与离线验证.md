## 候选行为与接口

独立目录：`/home/jetson/luhao/my_nav_carcar_obstacle_recovery`。从正式冻结发布复制源码与安装基线，不重建、覆盖或链接替换根工作区和正式发布。

流程为：`START_BLOCKED → 原导航取消及轮式停稳 → 等新扫描 → 一次无运动重新规划 → 仍受阻时选择安全短退 → Nav2执行及持续审查 → 动作终态与停稳核验 → 自动重新规划`。

- 任务保持 `EXPLORING` 或 `RETURNING`；`obstacle_escape` 单独报告内部阶段，网页显示自动避障、后退进度或停稳复核。不会以一次HTTP或Action成功冒充实际脱困。
- 主流程原0.22米原图、未知格、规划掩膜及防撞规则保留。后退单独检查当前朝向矩形和余量的完整直线扫掠，不要求先通过已经造成死锁的动态外接圆。
- 后方真实可观测空间、静态原图整段0.22米条件和制动尾部均须通过。不把NaN、无回波或未知格填白；不通过清除障碍栅格制造通路。
- 联合最多8帧、最长0.3秒真实扫描，经 `odom` 固定坐标将各扫描时刻雷达投到当前车身。所有真实端点均验障，后向新增区域须被有效视线连续覆盖；共同盲区仍拒绝。
- 根据可用空间选择较短距离和较低速度；没有几厘米的固定最小距离。软件可检查毫米级目标，但电机最小可控位移、实物制动和实际余量未验收。
- 默认单次不超过0.25米、0.03米／秒，最多6次、累计0.75米、总45秒。等待新扫描默认0.8秒。正常导航的新鲜轮式净位移至少0.25米才重置同一受阻位置预算；路径重规划变短不能重置。
- 后退经 `BackUp → /mapping/nav_raw → velocity_smoother → supervisor → collision_monitor → supervisor唯一出口`。正常RPP仍不倒车，后退阶段禁止同时前进、旋转或执行普通导航。
- 偏航超过0.05弧度、侧偏超过1厘米、明显前进、轮式过期、2秒无有效进度、扫掠新障碍、观测／地图过期均立即关闭输出并取消。安全条件变化先自动停稳复核，持续无安全动作或预算耗尽才进入人工暂停；取消终态超时锁停。
- 人工暂停、停车、接管、返程及质量恢复能抢占。迟到接受必须取消，迟到成功不恢复任务，真实终态和轮式停稳屏障保留。

新增核心位于 `retreat_planner.hpp`、`backup_motion.hpp`、`obstacle_escape.hpp`；监督器只负责接线及唯一速度门。候选XML开启 `obstacle_escape_enabled`；程序默认false，旧软件测试和独立入口不隐式获得新动作。
