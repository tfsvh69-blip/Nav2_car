# 已装配整车传感器对照步骤

2026-09-07 最新约定：整车建模宽统一为 216 mm。IMU 采用用户近似位置：相对
`base_footprint=(-40,-15,75) mm`，相对 `base_link=(-40,-15,45) mm`。位置精度未知，
安装角仍待采样。本说明更新此前要求拆车找芯片的步骤，现在无需拆车即可先确定输出轴向。

## IMU：只要做动作，把输出交给开发侧判断

现有 `imu_axis_observer` 已能输出六轴均值、标准差和峰值。先完成水平静止、水平手动
逆时针、恢复水平，再做车头抬高和左侧抬高。后两项只需 20～30°，用稳固支撑保持静止，
不用竖起整车。电机动力断开，保留读取控制板所需供电；不动雷达、相机安装螺丝。

构建：

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
export PATH=/opt/ros/humble/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
source /opt/ros/humble/setup.bash
/usr/bin/colcon build --symlink-install --packages-select rosmaster_vendor carcar_base carcar_hardware carcar_description
source install/setup.bash
```

终端 1：先关闭其他底盘驱动，串口占用检查无输出再启动。此入口是只读接口，没有运动命令接口。

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
fuser -v /dev/myserial /dev/ttyUSB0 2>/dev/null || true
ros2 launch carcar_hardware read_only_hardware_test.launch.py serial_port:=/dev/myserial
```

终端 2：逐项跟随回车提示操作，将五次输出保留并发回。逆时针指从上往下看整车，
让车头向车体左侧转；持续缓慢转动即可，注意线缆余量。

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
read -r -p '水平放稳，按回车采样30秒：'
ros2 run carcar_base imu_axis_observer --ros-args -p phase:=level -p sample_seconds:=30.0
read -r -p '按回车后开始手动水平逆时针旋转：'
ros2 run carcar_base imu_axis_observer --ros-args -p phase:=ccw -p sample_seconds:=15.0
read -r -p '恢复水平并放稳，按回车：'
ros2 run carcar_base imu_axis_observer --ros-args -p phase:=level -p sample_seconds:=10.0
read -r -p '车头抬高20～30度并稳固静止，按回车：'
ros2 run carcar_base imu_axis_observer --ros-args -p phase:=nose_up -p sample_seconds:=10.0
read -r -p '先放平，再把左侧抬高20～30度并稳固静止，按回车：'
ros2 run carcar_base imu_axis_observer --ros-args -p phase:=left_up -p sample_seconds:=10.0
```

开发侧使用水平重力向量确定上方，用倾斜相对水平的变化确定前方和左方，再检查旋转
角速度的轴和符号。20～30°倾斜时，向上的车体 X 或 Y 加速度分量约为正 3.4～4.9 m/s²；
Z 仍为正且通常更大。原消息可能尚未对齐车体，现场不用自行改符号。
这组数据用于判断安装旋转；若陀螺仪与加速度协议映射不一致，还需要补充俯仰/侧倾动态
采样分别验证。静止或单次旋转无法确认所有陀螺仪轴，也不能据此声称精确标定通过。

观察话题（持续命令用 Ctrl+C 停止）：

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /imu_sensor_broadcaster/imu --once
ros2 topic hz /imu_sensor_broadcaster/imu
```

结束时在只读 launch 终端 Ctrl+C，保持电机断电；如车体不稳，先扶稳并断电再整理线缆。

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 node list
fuser -v /dev/myserial /dev/ttyUSB0 2>/dev/null || true
```

## 雷达：用一个纸箱核对前、左、右

不用先理解欧拉角。车放平、轮子不动，将一个高于雷达扫描缝（217 mm）的纸箱依次放在
车前、车左、车右约 0.5～1 m 处；每次只移动这个纸箱，观察 RViz 哪一簇点跟着移动。
避开其他近处杂物，不要用低于扫描平面的物体。

先停止上述只读硬件 launch 和其他雷达测试。旧 `lidar_rviz_test.launch.py` 自带临时 TF，
本次使用 `lidar.launch.py` 配合整车描述，保证雷达安装 TF 只有一个发布者。

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
/usr/bin/colcon build --symlink-install --packages-select carcar_description carcar_lidar
source install/setup.bash
ros2 launch carcar_description view_model.launch.py
```

另开终端：

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch carcar_lidar lidar.launch.py
```

RViz 左侧点击 Add → By display type → LaserScan，Topic 选 `/scan`，Reliability 选
Best Effort，Fixed Frame 保持 `base_footprint`。切为俯视或旋转视图看清车头相机位置。
前方纸箱点簇应在模型相机朝向的一侧（+X），左方在模型左侧（+Y），右方在右侧（-Y）。
若三处都固定偏转 90°/180°，记录实际位置和显示位置；若左右互换，也原样记录。
这些现象分别用于排查安装 yaw 和扫描方向设置，现场先不修改参数。
该步骤确认平面方向；roll/pitch 还需确认车平放时雷达安装面水平，不能只由俯视点云判定。

观察与停止：

```bash
cd /home/jetson/luhao/my_nav_carcar
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /scan --once
ros2 run tf2_ros tf2_echo base_footprint laser_frame
```

停止 tf2_echo 后，在雷达及模型终端分别 Ctrl+C，关闭 RViz。

## 相机：先检查机械朝向，数据接入后再核对点云

车放平，用直尺沿车体前后中心线观察镜头正面是否与该线垂直，再从侧面看相机是否明显
朝上或朝下、从正面看两端是否一样高。先记录“水平朝前”或“向上/下、左/右偏”，无需
估计具体度数。模型暂用零安装角，表示相机水平朝前，不代表已经标定。

相机数据驱动尚待型号与链路确认，此处不提供未经验证的驱动启动参数。接通后通过
彩色图像和深度点云核对：把目标放在左红外中心正前方，点云转换到 base_link 后应位于
车前；再将目标移到车左/车右确认 Y 符号。只看图像正不正，不能证明 TF 安装角正确。
相机内部 optical frame 由 RealSense 驱动发布，不能按普通车体轴手工重复添加。

当前软件验证与历史命令见 `测试记录.md` 的 TF-003、IMU-002。上述现场对照尚待反馈。
