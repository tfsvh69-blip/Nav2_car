# NAV-018 实施与验证记录

日期：2026-10-26开始，2026-10-27继续。目标为用户已确认的“手动／自动建图与纯激光地图质量完善计划”。本记录区分代码、离线、软件房间和实机；未重启现有实车服务、未打开串口、未发送真实执行器命令。完整有效操作只在[手册39节](../../操作手册.md#nav-018-operation)。

## 业务链路与交付边界

| 环节 | 实现行为 | 可观察结果 |
|---|---|---|
| 工程与控制 | `new/resume`和`manual/automatic`独立；续建先首帧匹配及人工确认 | 网页与`/mapping/session/state`一致；确认前监督器拒绝自动运动 |
| 自动任务 | explore_lite只提交目标，C++监督器投影到已知自由区并检查足迹、geofence及整条规划路径 | `/mapping/autonomy/state`展示任务编号、阶段、目标、预算、健康原因及Action终态 |
| 运动所有权 | 手动门控／平滑后的自动速度先选一路，再通过原始扫描Collision Monitor与最终门控；取消后有界等待终态及轮式停稳 | `/mapping/cmd_vel`唯一出口；重复／旧任务请求不重启，超时锁停 |
| 预算与返程 | 第一次自动位置锚定20米，累计探索2400秒；自动0.10m/s／0.36rad/s；返程另限600秒 | 暂停／接管／刷新不重置；返程失败为部分候选，质量／传感故障不返程 |
| 数据处理 | 保留raw，Distance过滤独立话题；过滤标障、原始有效测量清障，删除值保留NaN | 不把去噪删除点转换成自由射线；动态层清理不编辑静态地图 |
| 质量保护 | 薄SLAM适配接纳／闭环事件；协方差有效性、轮式位移、激光方向分布与位姿跳变联合监督 | 弱特征／非回环大修正等风险撤销许可；取消停稳后冻结后续写图并保存不可发布诊断 |
| 保存与发布 | 独立资产、参数、来源、哈希和任务结果；保存完整、审核发布、启用分开 | 新候选默认隐藏；诊断不可发布；启用先停车再LoadMap，等待真实定位，不下发目标 |
| 巡检 | 独立纯激光XML入口；新profile不要求深度健康，保留RGB示教与拍照 | 不提供深度点云仍能执行单点；地图内容版本不符时旧任务继续被拦截 |

旧坏图不编辑、不覆盖；历史深度、6米、Cauchy和IMU比较入口保留。本轮保持3米、5厘米和原损失函数。风险监控不能证明绝对定位准确，尤其不保证检测所有缓慢漂移。现场必须物理排除落差和扫描面外障碍；2厘米低物需求后置。

## 来源、依赖与适配

- [explore_lite固定commit](https://github.com/robo-friends/m-explore-ros2/tree/326cf8a0b487c34246bb8f3326afbcd69576dc60)：BSD-3-Clause，使用单车前沿探索，保留许可证；本地适配详见[第三方说明](../../../src/third_party/SOURCES.md)。不引入多车合图。
- [laser_filters 2.0.10](https://github.com/ros-perception/laser_filters/tree/2.0.10)：BSD，处理二维LaserScan，无需为此引入PCL三维管线。首版仅Distance，RadiusOutlier边界读取顺序已修复并用ASan验证边缘，仍不作为默认模式。Distance阈值0.10米／2束是候选，细腿保留必须现场对照。
- [SLAM Toolbox 2.6.10](https://github.com/SteveMacenski/slam_toolbox/tree/2.6.10)：沿用已安装版本及原匹配算法／原损失；C++适配继承公开类、接Karto闭环监听，不复制匹配算法。原`/pose`改为可供新组合晚订阅者读取的transient-local；序列化前摘除自定义监听器，避免把指针写进旧工程。
- Nav2沿用本机Humble 1.1.20接口：ComputePathToPose、NavigateToPose、LoadMap及Collision Monitor。相较直接使用explore_lite，监督器补齐预算、唯一速度所有权、停止语义、地图变动复核和发布流程；相较自研探索器，仍复用上游前沿搜索和既有规划／控制器。新依赖 `nav2_collision_monitor` 为Apache-2.0；不升级系统ROS包。
- 本机TF2 `0.25.23`在软件房间出现MessageFilter注册与TF接收线程互锁。新增[私有兼容库](../../../src/carcar_tf2_compat/README.md)，固定geometry2 commit `9bc9e89285515c8981ecd829c9400807372468c4`，保留BSD-3-Clause；只修注册锁序、早到回调和取消映射，不更改头文件ABI，不覆盖系统库。对应上游[#992](https://github.com/ros2/geometry2/issues/992)、[#995](https://github.com/ros2/geometry2/issues/995)，这是项目局部修复，尚非上游正式修复。只有新XML子进程显式加载，普通环境`ldd`仍指向`/opt/ros/humble/lib/libtf2_ros.so`。
- JSON、Eigen、Boost／TBB沿用已有库，用于状态、二维几何和SLAM链接；不增加新的车端语言或Web框架。来源比较详见[自动建图调研](../2026-10-26-自动建图方案调研.md)与[激光调研](../2026-10-26-激光建图与导航链路调研.md)。

## 验证证据与已发现边界

原始证据目录：`log/autonomy_20261026_implementation/`。修改前完整差异及源码／文档检查点为 `before.patch` 和 `before_src_docs.tar.gz`；现行规则不回滚到检查点里的旧AGENTS。路线与索引实施前快照保存在本目录，旧结论没有改写为成功。

- `build_4.log`：首轮18包构建通过。前3次失败分别为SLAM公共库／Boost链接缺失、同一行EXPECT_THROW宏标签冲突；原日志保留。
- `core_tests_13.log`：15项状态／栅格、7项真实监督器接口与3项实际激光插件／ASan用例通过；覆盖取消／停稳、取消无终态、陈旧扫描、重复及旧请求、静止节流、延迟闭环与不明位姿跳变。
- `mapping_tests_1.log`：原网关、控制、保存／续建、HTTP和新增发布资产测试通过。原fake DOM事件方法缺失已修正；不是实车联调。后续新增故障重复心跳保存回归另记最终日志。
- `inspection_tests_13.log`：5个CTest目标全部通过，含21项控制台用例与实际Chromium桌面／手机示教。新增完全无深度输入的单点／停车启用地图用例通过。首次纯激光回归暴露步骤内仍强制`depth_enabled_`，修复后独立复测及整组通过；首次wiring失败源于隔离夹具遗漏顶层Launch参数，修正夹具后通过。
- 软件房间初次生命周期配置应答未完成，启动管理器延后3秒后继续验证；这只是启动编排修订，不能单凭一次运行认定消除了所有启动故障。
- 软件房间暴露上游连通前沿的均值目标落回车旁、action基名重映射没有形成监督路径；改用真实前沿栅格及显式action参数。又发现结束后取消已终态句柄导致异常，现已释放句柄并只处理本任务的取消。
- 晚启动可能错过静止时唯一首帧位姿，已为新组合增加transient-local。单独检查TF时还需识别SLAM按`transform_timeout=0.2s`前推时间戳的机制；传感器采样新鲜度与TF有效期分别校验，不通过放宽原始数据超时掩盖问题。

### 失败证据与修正

- `build_21.log`巡检测试最终链接因未链接OpenSSL::Crypto失败；补齐目标链接后`build_23.log`通过。大型集成夹具仅使用行号级调试信息减少Jetson链接负担，产品节点编译选项未降低。
- `mapping_tests_16.log`HTTP UDP用例先看到服务端就绪、误认为浏览器通道已打开；改为等待实际客户端open事件，`mapping_tests_24.log`整组通过，产品通道策略未放宽。
- `debug_controller_17.log`保存TF线程互锁堆栈。早期TF测试错误加载系统库也曾超时；修正测试自身库路径后，私有库对照通过。系统库保持原样，未修改ptrace或sysctl。
- `virtual_room_9/20/22`等早期日志及浏览器失败保留：分别涉及隐藏的重连按钮、保存后测试过早结束、返程操作等待窗口过短。现在浏览器实际等待返程／保存终态；测试房间保存后保留3秒供网页收取。Nav2进度窗口按低速转向从10秒改30秒，扫描、许可和命令超时未放宽。
- 手机截图发现从桌面宽度切换后仍用旧地图缩放，地图移出视口；画布尺寸变化时重新适配，`browser_autonomy_28/phone-manual.png`已确认显示真实模拟地图与扫描叠加。
- 新增“路径服务接纳但永不返回”接口回归，发现迟到的路径超时会重复进入STOPPING；现FAULT不再重入，持续锁停且输出零。`core_tests_26.log`该用例通过；取消超时不能借迟到反馈解锁。
- 激光插件另修正validator析构条件及虚析构，避免销毁／重配置时泄漏或未定义行为；RadiusOutlier仍不启用，默认Distance参数仍待现场对照。
- 2026-10-27复查修正三处离线缺陷，未启动实车：自动／诊断保存成功时不再把扫描转发重新打开；保存失败保留原因并在5秒后重试，重复故障心跳不能覆盖该原因。正常回环期间及回环后2秒内的轮式位移不再记为“扫描拒绝”。探索目标只在前沿0.8米窗口内投影，避免整图搜索堵住速度循环。回归：状态／栅格含1000×1000窗口、监督器、激光插件、发布策略，以及诊断保存失败后重试且转发计数不变。现场散点、几何和停车结论不变。

不以测试夹具报告的`success`替代子结果：返程成功／失败、探索完整／部分、文件保存完整、审核发布及正式启用分别保留。风险监控对缓慢漂移仍有限；没有录制本轮真实场地baseline bag，也没有完成原始／过滤实机场地对照。
