| 模块 | 实际职责与边界 |
|---|---|
| rosmaster_vendor / carcar_base | 厂商通信封装、正式串口所有者、底盘限速/超时停车、纯轮式里程计；现有Python资产保留 |
| carcar_hardware | 独立ros2_control协议/硬件插件及底层测试，不与正式驱动并行占串口 |
| carcar_description / carcar_lidar | URDF/固定TF/模型资源与RPLIDAR A1编排 |

| carcar_navigation | SLAM/AMCL/Nav2编排、受保护恢复、动态插件、速度联锁及会话证据 |
| carcar_mapping_console | C++常驻网页/任务进程组管理、独立运动门控、准备/网络工具；网页JS只作已授权交互，ROS节点在车端localhost |
| carcar_inspection / carcar_algorithms | 前者新增Vue网页、C++任务／示教、SQLite存储及RGB采集代码，默认配置模式；后者保留算法预留，状态见[应用说明](../src/carcar_inspection/README.md) |

随行建图的数据流：激光＋轮式里程计/TF→SLAM；地图/激光/估计车位→网页，RGB按需辅助；平板摇杆请求→独立门控→专用mapping速度→底盘。开机自动登录后网页待命，平板选择新建或旧工程并显式启动硬件；结束保存成功后关闭本次任务，网页保留。松手停车保留使能，后台/断联/故障/保存后重新使能；视频新鲜度不作随行遥控前提。续建初值须人工核对候选。具体接口、候选参数和完整步骤统一见[手册33节](操作手册.md#33-平板随行建图nav-017)。

R9按用户“换一种思路”新增局域网WebRTC数据控制路径，原WebSocket继续持有唯一操作者并交换信令，旧通道可选对照；未使能静默、每条新挑战一次周期回应，切换/关闭锁停，保持300ms车端截止。固定依赖与许可证见[专项调研](archive/2026-10-15-网页建图WebRTC控制通道调研.md)，构建/验证/部署结果只维护测试记录R9，操作统一手册33.14。传输替换不等于无线连续性已验收。

R10按用户“只需网页遥控建图、停止条件过多”收敛：静止就绪与运动有效期分开，静止/松手后不依赖操纵心跳，blur仅在仍按住摇杆时停车；运动签发后300ms截止不变，断开/页面隐藏/关键数据故障仍锁停。依据与本项目取舍见同一专项调研R10段；实施结果只维护测试记录R10，操作统一手册33.15。

R11针对仍偶发断联，隔离复现旧WebSocket2秒空闲回收连带关闭健康RTC；连接回收调整10秒，运动300ms截止不改，新增首个关闭错误及WS收帧/ping/pong诊断。固定原理与适用边界见[连接超时调研](archive/2026-10-15-网页建图WebSocket连接超时调研.md)，验证/部署只维护测试记录R11，流程手册33.16；旧现场未记录底层错误，不能将该路径当作唯一原因已经确认。
