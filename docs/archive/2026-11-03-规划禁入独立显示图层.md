# NAV-018-COSTMAP-002 规划禁入独立显示图层

2026-11-03。用户指出只换RViz颜色仍是大片紫色，明确要求规划禁入单独可开关，突出真实障碍／膨胀，不改变导航安全规则。沿用已授权的软件验证、备份、8080部署范围；发布前核验正式STANDBY/manual、无未保存任务和硬件占用。

## 设计与来源

Nav2 Humble [LayeredCostmap实现](https://github.com/ros-navigation/navigation2/blob/humble/nav2_costmap_2d/src/layered_costmap.cpp)先在primary栅格运行普通插件，再复制到combined栅格应用filters。被KeepoutFilter覆盖的软代价值不能从最终100还原。方案比较：

- 按最终颜色擦除：无法区分真实障碍，亦不能还原被覆盖的梯度，未采用。
- 网页重算膨胀：容易与真实参数、障碍源、足迹、更新时间不一致，未采用。
- 在普通插件末尾增加只读出口：读取已经完成的真实膨胀结果，不修改原值；采用。

独立C++ `DisplayCostmapLayer` 置于global的inflation后、filters前，通过 `/global_costmap/costmap_before_filters` 发布OccupancyGrid。编码依据 [Nav2 Humble官方发布器](https://github.com/ros-navigation/navigation2/blob/humble/nav2_costmap_2d/src/costmap_2d_publisher.cpp) 的0、1～98、99、100、-1语义；官方源码BSD-3-Clause，本轮独立实现，无第三方代码模块复制或新依赖。输出最多2.5Hz，400万格上限，DDS发送由100毫秒定时器完成，不在代价更新持锁期间发送；只保留最新待发帧，异常记录警告，原代价不变。

网页新增两项真实只读数据：`obstacle_costmap`为过滤前障碍膨胀，`keepout_mask`为 `/mapping/known_space_mask`。原global_costmap最终导航数据和接口保留。局部代价与原人工墙显示保持；人工墙已进入navigation_map，仍作为障碍参与全局膨胀，不属于可移除保护。

## 操作者效果与边界

“图层与地图说明”增加“规划禁入（仅显示）”，默认关闭；“全局代价”改名“全局障碍与膨胀”。开启禁入叠加低透明度棕色斜纹，关闭只隐藏斜纹，不发POST、不调用filter开关服务、不写参数。页面持续说明导航保护仍生效。透明不等于可通行。

障碍与膨胀图超过1.5秒隐藏；缺少合成前数据不会以最终图假充。禁入掩膜仅在变化时发布，不根据静态消息年龄错误隐藏；须存在新鲜全局基础图且frame、尺寸、分辨率、原点／角度一致才绘制。不匹配时暂不绘制并提示等待。禁入事件不使用图片0.4秒节流，避免快速掩膜更新被丢弃。原图像版本、旧任务迟到响应和失败重试保护保留。
