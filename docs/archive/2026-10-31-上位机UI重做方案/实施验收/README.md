## 实际改动与保留

候选源码位于 `/home/jetson/luhao/my_nav_carcar_ui_redesign`，这是独立 UI 候选目录，不是完整 ROS 工作区。

- 两页统一灰白工作面、蓝色主操作、细边框、6／9px 圆角、中文系统字体、等宽数值与焦点样式。桌面侧栏、常驻停车栏、地图与操作面板形成稳定布局。
- 建图任务面板移入右侧；手机先任务后地图。保留版本审核、图层、手动控制、恢复与附近返程入口。原有 DOM ID 无缺失、无重复。
- 巡检五页统一视觉规范；地图说明与导航诊断按需展开，触屏控件至少 44px（独立图层复选框使用整行标签点击区），手机速度选项固定两列。保留草图、点位、顺序、最终停车位、试拍、滑块、任务和照片功能。
- 增加跳过导航入口、装饰图标隐藏语义、输入／选择框焦点、减少动画偏好与长文本换行。按 [Vercel 规范](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md) 做定向检查；不宣称完整无障碍认证。保留既有健康门禁，未机械采用其“提交按钮始终可用”通则。
- 建图以当前 `my_nav_carcar_return_nearby_release` 为基线，`app.js`／`rtc_control.js` 逐字节未变；巡检业务 script 经相同格式化后完全相同。无新增运行依赖，无车端节点、接口、硬件配置、地图或 systemd 修改。
- 浏览器测试适配已折叠的详情入口；文本匹配允许模板格式化产生的空白，仍断言未选位置不能导航及对应 IDLE 状态。未删减原有业务断言。

[ui-changes.patch](ui-changes.patch) 包含 7 个候选文件差异。[ui-source.tar.gz](ui-source.tar.gz) 为可恢复源码，[ui-assets.tar.gz](ui-assets.tar.gz) 为 10 项可发布资源（含原许可证），[manifest.json](manifest.json) 为版本、差异与 SHA-256 清单。补丁的建图基线是冻结发布版，巡检基线是本次根源码检查点，不能直接对旧根工作区整包覆盖。Skill、测试夹具和假状态不进入发布资源。

## 待发布清单与边界

建议下一阶段只替换两处网页资产，不升级依赖、不重启硬件：建图替换当前冻结发布实际 `web_root` 下的 HTML／CSS；巡检发布候选 dist 至实际巡检服务 `web_root`。必须先只读核对两个实际路径、状态与源文件指纹，备份原资源，保留旧哈希资源供已经打开的页面完成加载；先复制新资产，最后替换入口 HTML。建图控制 JS 保持当前版本，通过 manifest 区分 UI 资产版本。

发布后检查 8080 根页面及 `/inspect/`、浏览器缓存更新、停车入口、状态与资源指纹。当前活动浏览器需刷新才显示新 UI；不能在操作者正在遥控／调角时要求刷新。若实际发布需要服务参数或系统配置变化，应重新说明影响，按项目同目录 `.backup` 和维护记录规则处理。

撤销时按此次备份逐项恢复旧入口和资产，不覆盖地图或其他未提交改动；后续新增资产可留存，避免删除正在加载的资源。本阶段没有替换线上文件，当前不需要执行回退。

尚未确认：实体平板触控和亮度条件下的可读性、实车导航／返程／滑块的现场效果，以及部署后的真实浏览器缓存切换。完整复现、停止与恢复见[操作手册 44 节](../../../操作手册.md#app-ui-001-operation)。
