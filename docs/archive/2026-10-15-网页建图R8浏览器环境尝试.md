# NAV-017-R8 Chromium环境尝试原文

日期：2026-10-15。本文保留失败尝试，不是当前有效操作入口。结果统一[测试记录R8](../测试记录.md)，当前操作见[手册33.13](../操作手册.md#mapping-dataflow-r8)。

目的：恢复既有真实浏览器触屏测试，区别于DOM替身下的协议回归。本机Chromium155要求GLIBC_2.38；宿主机版本不满足。只复制浏览器与crashpad到唯一`/tmp/r8b_*`目录，修改临时副本的ELF解释器，使用本机已有core24运行库；没有修改原snap、系统库或下载/安装软件。

实际结果：第一次crashpad仍使用宿主机解释器，GLIBC_PRIVATE失败；同时修正两个临时副本后，data URL的最小HTML渲染成功。实际测试在0ms注入的Page.navigate超时，没有进入应用。随后独立最小C++ HTTP服务器的请求日志为空，普通浏览器模式超时，single-process模式异常退出；未解决本机浏览器HTTP访问问题，不能登记触屏通过，也不能据此判用户平板不兼容。

证据目录：`log/mapping_dataflow_r8_20261015_HZd85l/`。其中`browser_smoke_stderr.log`、`browser_smoke2.log`、`chromium_touch_verified.log`、`browser_http_*.log`和`browser_http_smoke.cpp`分别保留失败、最小渲染、应用导航和独立HTTP对照。

以下是历史尝试命令，保留追溯，不建议当成已验证修复直接复用。它只改临时副本二进制，并在域219/localhost启动合成传感器与替身底盘；测试页面只连接127.0.0.1:18089，不访问实车8080或打开串口。原期望是实际DOM/CSS触屏的使能、拖动、松手、冻结与恢复通过，实际未达到。任一步失败退出；Ctrl+C后等待夹具清理，原系统浏览器保持原样，临时目录不成为日常入口，无系统回滚操作。

```bash
cd /home/jetson/luhao/my_nav_carcar
bash -e <<'BROWSER_TEST'
source /opt/ros/humble/setup.bash
source install/setup.bash
carcar_r8_browser=$(mktemp -d /tmp/r8b_XXXXXX)
ln -s /snap/core24/current/usr/lib/aarch64-linux-gnu/ld-linux-aarch64.so.1 "$carcar_r8_browser/ld"
for carcar_native in chrome chrome_crashpad_handler; do
  cp "/snap/chromium/current/usr/lib/chromium-browser/$carcar_native" "$carcar_r8_browser/$carcar_native"
  carcar_interp_offset=$(LC_ALL=C readelf -l "$carcar_r8_browser/$carcar_native" | awk '/INTERP/{print $2;exit}')
  [[ "$carcar_interp_offset" =~ ^0x[0-9a-f]+$ ]]
  printf '%s\0' "$carcar_r8_browser/ld" | dd of="$carcar_r8_browser/$carcar_native" bs=1 seek=$((carcar_interp_offset)) conv=notrunc status=none
done
for carcar_resource in /snap/chromium/current/usr/lib/chromium-browser/*; do
  case "${carcar_resource##*/}" in chrome|chrome_crashpad_handler) continue;; esac
  ln -s "$carcar_resource" "$carcar_r8_browser/${carcar_resource##*/}"
done
ulimit -c 0
ROS_DOMAIN_ID=219 ROS_LOCALHOST_ONLY=1 \
  MAPPING_TEST_CHROME="$carcar_r8_browser/chrome" \
  MAPPING_TEST_CHROME_LIBS=/snap/core24/current/usr/lib/aarch64-linux-gnu:/snap/chromium/current/usr/lib/chromium-browser \
  build/carcar_mapping_console/test_mapping_integration \
  --gtest_filter=BrowserIntegration.ActualBrowserEnableJoystickAndBoundedStallWithTabletLatency
BROWSER_TEST
```
