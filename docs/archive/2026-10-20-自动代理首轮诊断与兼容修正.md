下面读取新登录shell的代理环境，访问本地网页和无密钥API；不发送模型调用或运动命令。本地测试故意指定未监听的代理端口9，若HTTP200则证明当前IP被no_proxy直接绕过；若连接端口9失败，说明绕过无效。API预期CONNECT200、HTTP401、TLS_verify=0；不加-k，不关闭证书验证。HTTP403不能记作登录成功。网络请求最多10秒，可Ctrl+C结束，无需恢复硬件。

```bash
cd /home/jetson/luhao/my_nav_carcar
bash -n /home/jetson/.bashrc
bash -lc 'curl -x http://127.0.0.1:9 --connect-timeout 2 --max-time 3 -sS -o /dev/null -w "LAN HTTP=%{http_code}\n" http://192.168.180.181:8080/'
```
