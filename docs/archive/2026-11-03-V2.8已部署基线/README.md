## 现场反馈与待优化项

1. 希望网页通过 ROS 2 参数服务实时调整全局／局部代价图的膨胀半径、代价衰减系数等，显示实际读回值，并支持恢复基线及保存配置。
2. 探索目标偏向边界极端位置，到点后或下一点起步时的车头调整耗时明显；具体转向归属尚待按目标 UUID 和命令时序核对。
3. 下一目标有时位于车后，需要掉头或人工倒退；用户所称“倒车”尚未与自动负向速度命令逐项对应。当前自动 RPP 禁止倒车、速度平滑器前进下限为零、自动短退关闭。
4. 希望接近当前目标时提前准备并衔接下一点，提前衔接距离可以通过网页调节。连续候选已有代码，但历史效率门槛未通过，本标签没有启用。
5. 加入小障碍后，现场估计剩余宽度约为车宽三倍，自动行驶仍被取消，需要网页人工接管。宽度来自现场估计；拒绝层级与原因未查清，不能直接归因于全局膨胀半径。
6. 场地大块玻璃墙无法被当前 RPLIDAR A1 稳定识别。希望讨论反射率／灵敏度是否可调，以及适用的玻璃入图办法。材料反射率、设备灵敏度与已有测距点的 quality 过滤须区分。

上述为用户现场反馈和后续需求，不等于量化验收、根因结论或已实施功能。本次不宣称完整覆盖、长期稳定、玻璃检测或独立底盘看门狗问题已通过。
