# 导航算法与系统架构

本文件是小车导航系统的技术架构与核心算法全貌说明，详细记录当前小车在定位、建图、感知、路径规划、运动控制及任务调度中所采用的全部算法模型、数学原理及实机工程适配。

---

## 一、导航全系统算法总览

                                ▼

## 二、核心算法深度解析

### 1. 底盘运动学与里程计解算法（Kinematics & Odometry）

#### (1) 差速非全向退化模型（Differential Kinematic Model）
- **工程背景**：
  实车硬件为四轮麦克纳姆轮底盘，因整车搭载激光雷达、双目相机、计算单元及高容量电池后整体负载较重，麦轮微型辊子在地砖与地毯上承受较大侧向阻力，全向横移容易产生剧烈滑移与非线性里程误差。
- **算法设计**：
  在控制层与驱动层正式锁定为**非全向两轮差速等效模型**（`holonomic: false`），严禁横移（$v_y = 0$）与倒车（$v_x \ge 0$），将四轮动力学约束简化为高可靠的差速模型。

#### (2) 中点法数值航向积分算法（Midpoint Runge-Kutta Dead Reckoning）
- **计算流程**：
  1. 周期内采集左右两侧轮系编码器脉冲变化量，计算左右两侧线位移：
     $$\Delta s_L = \frac{\Delta s_{M1} + \Delta s_{M2}}{2}, \quad \Delta s_R = \frac{\Delta s_{M3} + \Delta s_{M4}}{2}$$
  2. 计算车体线位移增量 $\Delta s$ 与航向角变化量 $\Delta \theta$：
     $$\Delta s = \frac{\Delta s_R + \Delta s_L}{2}, \quad \Delta \theta = \frac{\Delta s_R - \Delta s_L}{L_{track}}$$
     其中 $L_{track} = 0.185\text{ m}$ 为底盘标定轮距，$D_{wheel} = 0.060\text{ m}$ 为标定轮径。
  3. 采用二阶中点积分法递推世界坐标系下的位姿 $(x, y, \theta)$：
     $$x_{k+1} = x_k + \Delta s \cdot \cos\left(\theta_k + \frac{\Delta \theta}{2}\right)$$
     $$y_{k+1} = y_k + \Delta s \cdot \sin\left(\theta_k + \frac{\Delta \theta}{2}\right)$$
     $$\theta_{k+1} = \theta_k + \Delta \theta$$
- **输出**：以 25.0 Hz 稳定发布 `/wheel/odometry` 与 `odom -> base_footprint` TF 坐标系。

### 2. 静态地图定位算法（AMCL: 自适应蒙特卡洛定位）

#### (1) 算法概述
AMCL（Adaptive Monte Carlo Localization）是一种基于**粒子滤波（Particle Filter）**的概率位姿估计方法，用于根据静态占用栅格地图和实时激光雷达扫描数据，消除轮式里程计的累计漂移。

#### (2) 差速运动预测模型（Differential Motion Model）
小车从时间 $t-1$ 移动到 $t$，里程计观测到位姿增量 $(\delta_{rot1}, \delta_{trans}, \delta_{rot2})$。AMCL 对每个粒子施加基于高斯噪声采样的差速运动学模型：
$$\hat{\delta}_{rot1} = \delta_{rot1} - \text{sample}(\alpha_1 \delta_{rot1}^2 + \alpha_2 \delta_{trans}^2)$$
$$\hat{\delta}_{trans} = \delta_{trans} - \text{sample}(\alpha_3 \delta_{trans}^2 + \alpha_4 (\delta_{rot1}^2 + \delta_{rot2}^2))$$
$$\hat{\delta}_{rot2} = \delta_{rot2} - \text{sample}(\alpha_1 \delta_{rot2}^2 + \alpha_2 \delta_{trans}^2)$$
其中 $\alpha_1 \sim \alpha_4$ 为旋转与平移运动噪声方差参数。

#### (3) 似然场观测模型（Likelihood Field Model）
对于激光雷达发射的每条光束 $k$，测量击中点的坐标为 $z_k$。似然场模型先离散预计算地图中每个网格到最近黑色障碍物的欧氏距离 $dist(z_k)$，每个粒子的测量似然度由混合概率密度函数给出：
$$p(z_k \mid x, m) = z_{hit} \frac{1}{\sqrt{2\pi}\sigma_{hit}} \exp\left(-\frac{dist(z_k)^2}{2\sigma_{hit}^2}\right) + \frac{z_{rand}}{z_{max}}$$
- 当前配置参数：$z_{hit}=0.5$, $\sigma_{hit}=0.2$, $z_{rand}=0.5$, $z_{max}=0.05$。
- **优点**：无需对每条激光束执行耗时的光线投射碰撞检查，计算极其快速，对微小障碍物形变和传感器噪声具有极强的鲁棒性。

#### (4) KLD 自适应重采样（KLD-Sampling）
AMCL 依据当前位姿后验概率分布的离散程度，通过 Kullback-Leibler 散度（KLD）动态计算所需最小粒子数量：
$$k = \frac{1}{2\epsilon} \left\{1 - \frac{2}{9(k-1)} + \sqrt{\frac{2}{9(k-1)}} z_{1-\delta}\right\}^3$$
- **当前约束**：`min_particles: 500`，`max_particles: 2000`；
- **效果**：在初始定位阶段粒子数自动扩大到 2000 以覆盖全局假设；在定位收敛后，粒子数迅速缩减至 500 左右，大幅降低 Jetson 算力负担。AMCL 唯一负责发布 `map -> odom` TF。

### 3. 环境表征与代价地图算法（Layered Costmap 2D）

系统维护全局代价地图（Global Costmap）与局部代价地图（Local Costmap），采用分层插件架构：

#### (1) 静态层（StaticLayer）
加载地图服务器 `map_server` 发布的已知静态占用栅格地图（`nav002_20260909_164237.yaml`，0.05 m/cell）。占用率网格被赋予基础静态代价（致命障碍赋予 254，空闲区域赋予 0）。

#### (2) 障碍物光线追踪层（ObstacleLayer）
- **算法**：采用经典 Bresenham 直线光线追踪（Ray-tracing）算法。
- **数据流**：以 10.4 Hz 订阅 `/scan`。
- **机制**：
  - **Clearing（自由空间清除）**：在光线从传感器原点到实测击中点之间 `[0.10 m, 3.00 m]` 的空间内，将网格代价清除为 0；
  - **Marking（动态障碍物标记）**：在光束击中点处将对应栅格标记为致命代价 254。

#### (3) 指数衰减膨胀层（InflationLayer）
- **算法模型**：基于多源最短距离变换的指数代价衰减算法。
- **数学表达式**：
  对于距离最近障碍物为 $d$ 的网格单元：
  - 若 $d \le r_{inscribed}$（小车内切半径 0.17 m）：赋予致命代价 $C = 254$（Lethal）；
  - 若 $r_{inscribed} < d \le r_{inflation}$（膨胀半径）：
    $$C(d) = 253 \times \exp\left(-cost\_scaling\_factor \times (d - r_{inscribed})\right)$$
  - 若 $d > r_{inflation}$：赋予无障碍零代价 $C = 0$（Free）。
- **首轮安全初始值（待实机确认）**：
  - `inflation_radius: 0.35 m`，保留车体外的安全膨胀区；
  - `cost_scaling_factor: 5.0`；
  - `footprint_padding: 0.0`。

### 4. 全局路径规划算法（Navfn Planner）

#### (1) 算法模型：波前扩展与动态规划（Wavefront Expansion / Dijkstra）
`nav2_navfn_planner` 是基于经典的 Dijkstra 最短路径搜索与快速行进算法（Fast Marching Method）构建的全局路径规划器。

#### (2) 规划原理与步骤：
1. **势能场初始化**：以用户下发的导航目标点（Goal Pose）为势能为 0 的绝对零势能汇点（Sink）；
2. **8 连通波前扩散**：在全局代价地图上，向外逐层扩展波前，计算每个空闲网格到达目标点的最小累积代价 $U(x, y)$，将障碍物高代价叠加进势场；
3. **连续负梯度追踪**：从机器人当前位姿（Start Pose）出发，使用双线性插值连续计算势能场的负梯度方向 $-\nabla U(x, y)$，沿梯度下降曲线追踪至目标点，生成由一系列离散二维位姿组成的平滑全局路径点集（`nav_msgs/Path`）；
4. **安全约束**：开启 `allow_unknown: false`，严格禁止路径穿过未建图的未知灰色区域。

### 5. 局部轨迹规划与避障控制算法（DWB Local Planner）

#### (1) 算法模型：动态窗口法（Dynamic Window Approach, DWA）
DWB 控制器是 ROS 2 Nav2 对经典动态窗口法的重构进阶实现。其核心是在**机器人速度搜索空间中采样、结合物理加速度极限进行前向仿真，并通过多准则打分函数选优**。

#### (2) 速度搜索空间计算（Dynamic Window）
在控制周期 $\Delta t = 0.05\text{ s}$（20.0 Hz）内，结合电机物理极限与加减速约束，动态确定当前可达的速度区间：
$$V_d = \left\{(v, \omega) \mid v \in [v_{cur} - a_{dec}\Delta t, v_{cur} + a_{acc}\Delta t] \cap [v_{min}, v_{max}],\ \omega \in [\omega_{cur} - \alpha_{dec}\Delta t, \omega_{cur} + \alpha_{acc}\Delta t] \cap [\omega_{min}, \omega_{max}]\right\}$$
- **首轮实机约束（待确认）**：
  - $v_x \in [0.0, 0.10\text{ m/s}]$（纯差速正向前进，禁止倒车 $v_{min}=0$ 与横移 $v_y=0$）；
  - $\omega_z \in [-0.20, 0.20\text{ rad/s}]$；
  - 加速度限制：`acc_lim_x: 0.20 m/s²`，`acc_lim_theta: 0.40 rad/s²`。

#### (3) 候选轨迹数值前向仿真（Forward Simulation）
在预测时域 `sim_time: 1.5 s` 内，对采样的每对 $(v, \omega)$ 进行数值欧拉积分，生成一条预演圆弧轨迹分支：
$$x(t) = x_0 + \int_0^t v(\tau) \cos(\theta(\tau)) d\tau, \quad y(t) = y_0 + \int_0^t v(\tau) \sin(\theta(\tau)) d\tau$$

#### (4) 多准则轨迹评估体系（Trajectory Critics 打分函数）
DWB 采用 7 组独立的评分器对每条预演轨迹打分，最终总分最高的轨迹被选中执行：
$$\text{Score} = \sum_{i} \left(\text{Scale}_i \times \text{Critic}_i\right)$$

| 评估器（Critic） | 权重（Scale） | 评估机理与作用 |
| :--- | :--- | :--- |
| **`PathDist`** | 24.0 | 评估轨迹终点距全局参考路径的距离，引导小车贴合全局路径。 |
| **`GoalDist`** | 20.0 | 评估轨迹末端与最终目标点的欧氏距离，驱动小车向终点前进。 |
| **`PathAlign`** | 24.0 | 评估车头朝向与全局路径切线方向的一致性，防止侧滑偏航。 |
| **`GoalAlign`** | 20.0 | 评估车头朝向与最终目标姿态的夹角，保证到点前顺利对齐航向。 |
| **`BaseObstacle`** | 0.02 | **安全红线检查**：沿候选轨迹对小车矩形包络（$x=\pm 0.20\text{ m}, y=\pm 0.17\text{ m}$）进行多边形栅格投影，一旦压到致命代价直接判定该轨迹**非法并废弃**。 |
| **`RotateToGoal`** | 24.0 | 专用于到达目标点容差范围内的原地自转对齐。 |
| **`Oscillation`** | 默认使能 | 振荡抑制器：严格惩罚正负速度来回切换，杜绝车身左右摇摆。 |

### 6. 速度整形与动力学平滑算法（Velocity Smoother）

- **算法模型**：二阶加减速度前向积分限幅与梯形速度曲线滤波（Trapezoidal Velocity Profile）。
- **控制频率**：20.0 Hz。
- **作用机理**：
  局部规划器输出的速度往往存在微小的阶跃跳变，平滑器将其限制在加减速极限内（线加速度 $[-0.20, 0.20]\text{ m/s}^2$、角加速度 $[-0.40, 0.40]\text{ rad/s}^2$），消除起步冲击并保护减速电机齿轮箱。
- **安全看门狗（Watchdog）**：
  配置 `velocity_timeout: 0.20 s`。若上层导航节点出现卡顿、崩溃或异常退出，超过 0.20 秒未收到新指令，平滑器立即主动向底盘输出全零速度，与底盘底层固件的 0.30 s 看门狗形成双重梯次保护。

---

### 7. 任务调度与高层决策架构（Behavior Tree Navigator）

- **调度架构**：基于 BehaviorTree.CPP 引擎的反应式行为树。
- **树结构设计**：采用单向流水线序列（`PipelineSequence`）。
- **无恢复机制设计理念**：
  小车严格剔除 Nav2 官方默认的脱困自转（Spin）、倒车（BackUp）和清除代价地图（ClearEntireCostmap）等激进动作。
- **执行逻辑**：
  以 1.0 Hz 频率周期性调用全局规划器重规划 $\rightarrow$ 将新路径流水线式注入局部控制器跟随 $\rightarrow$ 遭遇无法绕过的死路时，行为树直接返回 `FAILURE` 并在原地安全刹停，杜绝在未知窄通道中因盲目恢复而造成车体冲撞。
