## 修改与证据边界

`MappingStatusMonitor`封装原控制台的查询地址、同步HTTP读取、原子缓存和后台线程。构造不启动；`start()`重复调用不重复建线程，空地址不查询；`blocks_inspection()`只读缓存；`stop()`重复安全，析构回收线程。停止后保留最后缓存，可再次启动。调用方串行管理生命周期。

仍为查询后5次100ms等待，保留300ms收发套接字设置。初始缓存false；忙态三种字符串为true，HTTP非200／非法或非对象JSON为true，其他状态／缺少字段为false，连接／读写或字段类型异常为false。只读缓存不是运动许可。连接总耗时及异常时互斥策略留作独立行为评估，本轮不扩展为硬截止保证。

HTTP／ROS接口、参数、存储格式、导航状态机、默认开关及硬件资源保持原行为；`inspection_mapping_status`是包内静态库，不增加节点或依赖。控制台保留原请求队列与状态机，网络查询通过四个生命周期／读取操作使用。
