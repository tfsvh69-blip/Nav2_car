### 机制说明

Nav2 的 ObstacleLayer（障碍层）通过 marking（标记）与 clearing（射线清除）更新代价图，是否有有效清除射线取决于可视性、测距、传感器输入和量程；不能因为历史障碍“变老”就认为它可以安全删除。SLAM 保存的静态占用地图与运行时障碍层也不是同一数据源，后者清除不等于改写前者的已保存地图。

这轮证据优先支持**历史障碍未获后续有效清除观测**，而不是认定 Nav2 清除程序失效。现场已有人员/物体近距离出现，因此不采用按时间强制清障、关闭 ObstacleLayer、减小安全包络、或直接指令返程。

1. **先做现场净空确认。** 在电机动力断开情况下移开靠近扫描平面的人/物/线缆；若固定家具导致空间过窄，只能断电后人工挪车到通道中央，确认稳定后再恢复动力。暂未收到“清理完成”的反馈，不自动代办。

3. **再授权短程实车。** 只有现场明确无落差、净空足够、有人看护并能立即断电，且起步安全检查和传感器健康通过后，才按已有短测流程做转向→短行驶→暂停停稳；记录实物是否抖动、停车距离及原始录包。
4. **最后再验证返程。** 返程须通过真实全局代价图的路径预检和碰撞安全检查，再验证实体回位；保存独立地图、正常结束，完整三轮覆盖仍作为独立待验收项目。
