# 控制板、串口与电池状态

最后更新时间：2026-09-06

## 当前配置

| 项目 | 当前值 | 说明 |
|---|---|---|
| 控制板 | Yahboom Rosmaster，驱动库 V3.3.9 | 精确板号待确认 |
| 底板串口 | `/dev/myserial -> /dev/ttyUSB0`，115200 | CH340/CH341，当前稳定 |
| 雷达串口 | `/dev/serial/by-id/usb-Silicon_Labs_CP2102_USB_to_UART_Bridge_Controller_0001-if00-port0` | 不得与底板串口混用 |
| 车型 | `car_type: 1` | X3 麦克纳姆配置，与当前四轮目标一致 |
| 全向运动 | `holonomic: true` | 使用 `linear.x`、`linear.y`、`angular.z` |
| 命令超时 | `0.5 s` | 超时写零停车 |
| 电池电压 | 控制板已实机回传 11.8～12.1 V 日志 | `/battery_state.voltage` 可用 |
| 电量百分比 | 默认以 9.6～12.6 V 线性估算 | 电池型号未确认，当前不能作为低电回充判据 |

原厂库只由工作空间中的 `rosmaster_vendor` 提供，不执行资料包中的
`sudo python3 setup.py install`，避免污染系统 Python。底板串口任何时刻只允许一个进程打开。

## 启动前检查、构建和启动

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
ls -l /dev/myserial
groups
fuser -v /dev/ttyUSB0 /dev/myserial 2>/dev/null || true
colcon build --symlink-install \
  --packages-select rosmaster_vendor carcar_base carcar_description carcar_bringup
source install/setup.bash
ros2 launch carcar_bringup robot.launch.py
```

`fuser` 有输出时先正常停止占用底板串口的节点。正式四轮组合运动尚未完成前，整车必须
架空或留在可立即断电的空旷区域，速度保持低值。

## 状态观察

另开终端：

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 topic echo /battery_state --once
ros2 topic echo /diagnostics --once
ros2 topic hz /imu/data_raw
ros2 topic hz /wheel/odometry
```

当前只把 `voltage` 当作真实遥测值。`percentage`、`power_supply_status` 和 LiPo 类型是
软件默认推导，需确认电池、充电器和负载压降后再用于产品逻辑。

## 停止与恢复

在启动终端按 `Ctrl+C`，确认车辆停止后执行：

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 node list
fuser -v /dev/ttyUSB0 /dev/myserial 2>/dev/null || true
```

异常运动、异响、线缆发热或软件无法停车时，立即切断电机主电源；软件超时不替代硬件急停。
