# NAV-017-R17：先比较，再加入一个算法候选

日期：2026-10-20。用户要求先推送当前代码并打标签，再逐项测试、选择算法。本轮发布基线为远端main的 `57ef0804ac755b4309cbff6446901044a7ea20a2`，附注标签 `V2.5` 指向同一提交，描述逐字为：“完成了上位机及 UI，现在测试可以正常建图，巡检这边还没有测试。”算法工作独立于该基线。

## 本轮只比较什么

比较SLAM Toolbox现有Ceres插件的默认二次损失None、HuberLoss、CauchyLoss。一次只改变损失函数，使用相同节点、连接、初值、协方差、求解器选项和固定种子；原扫描匹配算法不变。只给离线筛出的Cauchy建立一个候选入口，维持原3m范围；与此前6m候选分开，没有同时加入ICP、运动补偿或IMU。

损失函数决定约束误差受到多大的惩罚。默认平方惩罚可能让个别错误连接牵动整图；鲁棒核降低大残差的影响，也可能削弱本来有用但误差大的约束。Cauchy对大残差的压制更强，不能仅由一个异常场景推断它普遍更好。

调用的是本机已安装的 `solver_plugins::CeresSolver`，不是另写优化器。固定SLAM Toolbox **2.6.10**，上游Huber/Cauchy均使用内置尺度 **0.7**；这个尺度作用于协方差归一化后的残差，不是米或角度。Ceres为 `2.0.0+dfsg1-5`、Eigen为 `3.4.0-2ubuntu2`、TBB为 `2021.5.0-7ubuntu2`，均为本机现有依赖，没有升级或安装系统包。

## 可重复测试与选择规则

[C++比较入口](../../../src/carcar_mapping_console/src/slam_loss_benchmark.cpp)；完整构建、运行和恢复只维护于[手册33.21](../../操作手册.md#slam-loss-candidate)。程序不打开串口、不启动硬件、不发布速度；ROS节点关闭参数服务，仅供插件初始化。只读取可信的本仓库序列化图。

合成图是21个二维位姿组成的5m＋5m直角L形路径，坐标为合成参考系，位置单位米、航向单位弧度；它不是激光栅格地图，没有相机视场、实时车辆或障碍物。第一节点固定，连接标准差为位置0.03m、角度0.02rad，这些是测试权重，未写入实际标定。五个固定种子为11、23、47、59、71。

五个场景各运行三种方法、五组初值，共**75次求解**：

1. 正确约束、接近真值的初值。
2. 正确约束、第二段初值偏转30°，检查能否从90°被估计成120°的初值恢复。
3. 正确连接有独立高斯噪声（位置标准差0.01m、角度0.005rad），检查鲁棒处理对正常数据的代价。
4. 添加一条含1m/0.7m位置误差及30°朝向误差的错误跨段连接。
5. 所有连接与初值都一致地错成120°，检查缺少正确外部约束时的能力边界。

筛选门槛在运行比较前写入代码/报告：两种理想正确约束场景的最坏位置RMSE≤0.03m、最坏航向误差≤1°；正常带噪场景相对默认最坏误差增加不超过20%加0.01m/0.2°；错误连接场景位置与航向最坏误差至少减半，再按位置RMSE选择候选。这是本轮工程筛选规则，不是产品标准。共同错误观测场景单独报告，不参与胜者排名；如果没有合格鲁棒候选，回归返回失败。

首轮60次先覆盖四个场景，[原始报告](report_initial_60.json)保留；随后因正常测量也可能被降权，增加正常带噪场景和退化限制，最终为75次。[最终机器报告](report.json)含每次结果、聚合、准入判定及无实物真值标记。

## 结果：Cauchy进入独立候选

以下均为合成测试的五组初值中最坏结果，不能当作小车实机精度：

| 方法 | 单条错误连接：位置RMSE | 单条错误连接：最坏航向误差 | 正常带噪：最坏航向误差 |
|---|---:|---:|---:|
| None | 0.5676m | 12.412° | 1.493° |
| Huber | 0.0667m | 1.159° | 1.538° |
| Cauchy | 0.0050m | 0.103° | 1.608° |

两种鲁棒方法都通过本轮门槛；按既定异常场景指标选Cauchy。正常有噪声时Cauchy的航向误差略大于默认，代价必须保留。所有观测一致地错30°时，三种方法都保留约30°误差，说明损失函数不能补出缺失的真实信息。

只增加 `config/slam_cauchy_candidate.yaml` 及 `launch/tablet_cauchy_candidate.launch.xml`。去掉注释与空行后，相对原基线唯一参数差异为 `ceres_loss_function: CauchyLoss`；范围仍3m，其余扫描、闭环、运动及停车参数不变。原入口继续默认None。新建图单独保存，候选不从旧图隐式续建。

## 昨晚保存图的敏感性检查

只读 `20261019_223507_5ec7cfe3/graph.posegraph`，含637节点、976连接，每种方法从同一保存状态开始重新优化。CSV记录的是保存图参考系内估计位姿，颜色/显示尺度不参与比较，本轮没有生成或覆盖新的栅格地图。

| 方法 | 相对原保存状态的位置变化RMSE | 航向变化RMSE | 归一化残差范数>3的连接数 |
|---|---:|---:|---:|
| None | 0.363m | 5.295° | 66 |
| Huber | 0.366m | 1.818° | 49 |
| Cauchy | 0.446m | 1.498° | 37 |

这些是**变化量与约束一致性，不是精度或修复量**；阈值3是归一化残差范数，没有赋予实机统计置信度。默认方法的共同平方残差更低也是其优化目标的预期，不据此单独定胜负。保存图没有独立建筑/轨迹真值，本轮也没有回放所有原始扫描及时间链，不能证明昨天问题由错误闭环引起或已修复。原工程保留，候选只供下一轮新建对照。
