## P1.5：IMU 后置评估（不阻塞首次导航）

- [ ] 断电露出控制板，拍含车头标记、IMU 芯片/板轴丝印和毫米尺的垂直俯视图；以轮心

- [ ] 用只读 `imu_axis_observer` 按静止角速度→逆时针→水平加速度顺序完成基线，再进行
  车头和左侧分别抬高约 20～30°后的静止采样，
  确认三轴排列和符号后再写入驱动映射或 `imu_link` TF。
- [ ] 水平静止数十秒，采集 `angular_velocity.z` 并计算均值和标准差，分别记录零偏与噪声。
- [ ] 按 X 前、Y 左、Z 上固定车体坐标，人工逆时针旋转小车；必须观察到
  `angular_velocity.z > 0`。不满足时先修驱动轴映射或 `imu_link` 安装 TF，不改 EKF 参数。
- [ ] 水平静止检查 `ax≈0`、`ay≈0`、`az≈+9.81 m/s²`。当前仅有
  `|a|≈9.174 m/s²`，因此加速度标定尚未通过。
- [ ] 上述检查通过且纯轮式里程计、基础导航稳定后，建立第一版 `robot_localization`

  姿态、全部线加速度和磁力计输入。
- [ ] 二维地面导航默认不融合线加速度；只有实测显示明确收益时才单独立项。
- [ ] Madgwick、线加速度和磁力计均作为后置独立实验；每次只增加一种信息源并与上一版
  对比，不一次性全部启用。
