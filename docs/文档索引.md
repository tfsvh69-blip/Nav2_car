# 项目文档索引

本目录中的项目文档统一使用中文，并随代码和硬件状态持续维护。

| 文档 | 用途 | 维护方式 |
|---|---|---|
| [架构设计](架构设计.md) | ROS 2 分层架构、包职责和后续实施顺序 | 架构变化时更新 |
| [硬件台账](硬件台账.md) | 实际硬件、接线、驱动、端口和未确认事项 | 每次硬件反馈后更新并追加变更记录 |
| [测试记录](测试记录.md) | 从底层到上层的完整测试命令和实测结论 | 只追加，不删除历史测试 |
| [硬件配置](硬件配置.md) | 控制板和串口通用配置说明 | 安装方式变化时更新 |
| [电机测试](电机测试.md) | 当前 M1/M2 点动测试的专题说明 | 保留，后续迭代追加修订 |
| [激光雷达 Humble 迁移与测试](激光雷达Humble迁移与测试.md) | RPLIDAR A1 在 Jetson/Humble 上的构建、启动、RViz 验证和停止流程 | 雷达入口或实测结论变化时更新 |

## 文档原则

- `硬件台账.md` 回答“现在实际接了什么、确认了什么”。
- `测试记录.md` 回答“如何复现测试、当时得到了什么结果”。
- 专题文档回答“某个模块如何使用和排查”。
- README 只保留快速入口，详细命令放在测试记录和专题文档中。
