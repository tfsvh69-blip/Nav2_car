# M1/M2 电机按键测试

> 状态更新（2026-09-06）：本文以下入口均为保留的底层回归工具，不是当前主线。
> 当前四轮轮位和机械方向已由 `MOTOR-004` 确认，`MOTOR-005` 因重复度高不再要求实机
> 执行。下一次只做一组低速“前进、横移、旋转”组合运动。现行任务见
> [项目现状与路线](项目现状与路线.md)。

这个测试节点绕过正式底盘运动学，只控制控制板的 M1、M2，且每次发送时都明确将 M3、M4 写零。默认 PWM 上限为 20%，只响应前进/后退，0.6 秒收不到新指令便自动停车。

## 安全准备

1. 将车轮架空，确保轮胎接触不到人、线缆和桌面。
2. 准备好控制板电源开关；先不要运行 `carcar_bringup robot.launch.py`。
3. 同一时间只能有一个节点打开 `/dev/myserial`。
4. 当前已确认 `/dev/myserial` 指向 `/dev/ttyUSB0`，运行前仍建议再次检查。

## 终端 1：启动二电机测试节点

```bash
conda deactivate  # 若当前终端启用了 Conda
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select rosmaster_vendor carcar_base
source install/setup.bash
ros2 launch carcar_base motor_test.launch.py
```

启动时节点立即向 M1～M4 写零。看到 `M1/M2 test mode active` 后再操作键盘。

## 终端 2：键盘发布 `/cmd_vel`

```bash
conda deactivate  # 若当前终端启用了 Conda
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

按键：

- `i`：M1、M2 正向，持续最多 0.6 秒。
- `,`：M1、M2 反向，持续最多 0.6 秒。
- `k` 或其他非控制键：立即停车。
- `Ctrl+C`：退出键盘节点并发送零速；再在终端 1 中退出测试节点。

每按一次键都会发布一帧 `/cmd_vel`。这是有意设置的短点动测试；需要继续转动时再次按键，不要在首次测试中提高超时时间。

## 电机方向校准

若正向指令下某个轮子的机械前进方向相反，停止节点后翻转对应符号：

```bash
# 示例：只反转 M2
ros2 launch carcar_base motor_test.launch.py motor_2_sign:=-1
```

如果两个都反了，可同时传入 `motor_1_sign:=-1 motor_2_sign:=-1`。确认方向之后，把结果写回 `src/carcar_base/config/motor_test.yaml`。

若 20% PWM 无法克服电机静摩擦，在确认供电和接线后可小幅提高，例如：

```bash
ros2 launch carcar_base motor_test.launch.py max_pwm_percent:=25
```

测试过程中节点日志会显示实际发送给 M1、M2 的 PWM 百分比。

## MOTOR-002：底板运动闭环与安全停车

`MOTOR-001` 使用 `set_motor()` 直接 PWM；正式插件是否采用底板闭环还需要独立验证
`set_car_motion()`。本测试把命令入口隔离为 `/motor_closed_loop_test/cmd_vel`，完整启动、
观察、停止命令和现场结果统一记录在 `docs/测试记录.md` 的 `MOTOR-002`。

显式零速子步骤使用 `safe_velocity_pulse`：它不会打开串口，只在隔离话题恰好存在一个
订阅者时，发送固定 `+0.10` 命令，并在约 0.20 秒后重复发送零速。不得把它重映射到
正式 `/cmd_vel`，也不得在轮子未架空时运行。

## MOTOR-004：四电机逐轮轮位与方向辨识

当前四轮麦克纳姆底盘使用独立脚本按 `M1 → M2 → M3 → M4` 自动测试。每次只有一路
收到 `+15%` PWM，固定持续 3 秒；路间四路全零 2 秒。这里的正 PWM 不等于车体前进，
实际轮位和机械方向必须现场观察后登记。本入口不会启动 SLAM、AMCL/NDT、Global
Planner、MPPI/RPP、正式 bringup、里程计或 `ros2_control`。

运行前必须将四轮全部架空、准备好电机电源开关，并关闭所有可能占用 `/dev/myserial`
的底盘节点。完整构建、启动、观察、停止、恢复命令及反馈表见 `docs/测试记录.md` 的
`MOTOR-004`。测试启动命令为：

```bash
cd /home/jetson/luhao/my_nav_carcar
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
colcon build --symlink-install \
  --packages-select rosmaster_vendor carcar_base
source install/setup.bash
ros2 node list
fuser -v /dev/ttyUSB0 /dev/myserial 2>/dev/null || true
ros2 run carcar_base motor_mapping_sequence
```

启动立即写零；每路由独立定时看门狗在 3 秒时归零，主线程、`Ctrl+C` 和正常退出路径
再次重复写零。软件异常停车不代替硬件急停：任一轮未按时停止、异响、抖动、接线发热
或运动异常时，立即关闭控制板电机电源，不要用手阻挡轮子。

2026-09-05 实机结果：按车头朝俯视图上方解释，M1=左前且正转、M2=右后且反转、
M3=右前且正转、M4=左后且反转；四路均在约 3 秒后停车，全程无异常。四轮期望正转的
端口命令符号为 `[+1, -1, +1, -1]`。`MOTOR-004` 已通过，完整日志结论仍以
`docs/测试记录.md` 为准。
