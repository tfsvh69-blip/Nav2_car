## 常用命令速查

以下命令均从工作空间根目录执行：

```bash
cd /home/hao/luhao/ros2/my_nav2_car
```

### 检查雷达连接

```bash
./scripts/check_lidar.sh
ls -l /dev/ttyUSB*
lsusb | grep -Ei 'CP210|Silicon Labs|RoboPeak|SLAMTEC'
```

如果 `/dev/ttyUSB0` 存在但当前用户没有权限，长期解决方法为：

```bash
sudo usermod -aG dialout "$USER"
```

执行后注销并重新登录。仅用于临时测试时可以执行：

```bash
sudo chmod a+rw /dev/ttyUSB0
```

不要使用 `sudo` 启动 ROS 节点或 RViz。

### 构建与启动

```bash
./scripts/build.sh
./scripts/run_lidar.sh
```

雷达不是 `/dev/ttyUSB0` 时，显式传入实际设备：

```bash
./scripts/run_lidar.sh /dev/ttyUSB1
```

### 加载 ROS 2 环境

新终端执行 ROS 2 命令前先运行：

```bash
cd /home/hao/luhao/ros2/my_nav2_car
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_LOG_DIR="$PWD/log/ros"
```

### 检查扫描数据

```bash
ros2 topic list
ros2 topic info /scan --verbose
ros2 topic hz /scan
ros2 topic echo /scan --once
```

预期 `/scan` 类型为 `sensor_msgs/msg/LaserScan`。查看雷达当前参数：

```bash
ros2 param get /sllidar_node frame_id
ros2 param get /sllidar_node scan_mode
ros2 param get /sllidar_node angle_compensate
ros2 param get /sllidar_node scan_frequency
```

### 检查坐标变换

```bash
ros2 run tf2_ros tf2_echo base_link laser
ros2 topic info /tf_static
```

RViz2 的 Fixed Frame 应为 `base_link`，LaserScan Topic 应为 `/scan`。

### 手动选择扫描模式

停止已有雷达进程后启动 `Express` 模式：

```bash
ros2 launch inspection_bringup lidar_test.launch.py \
  serial_port:=/dev/ttyUSB0 \
  serial_baudrate:=115200 \
  scan_mode:=Express \
  use_rviz:=true
```

需要排查兼容性时切换到 `Standard`：

```bash
ros2 launch inspection_bringup lidar_test.launch.py \
  serial_port:=/dev/ttyUSB0 \
  serial_baudrate:=115200 \
  scan_mode:=Standard \
  use_rviz:=true
```

若只验证数据、不启动 RViz：

```bash
ros2 launch inspection_bringup lidar_test.launch.py use_rviz:=false
```

### 构建与测试检查

```bash
colcon test
colcon test-result --verbose
```

## 维护规则

1. 用户给出明确实测反馈后，当次更新对应模块、日期和复现命令。
2. 不确定的测试条件填写“待补充”，不根据经验猜测。
3. 理论规格不得替代实体实测结果；两者不一致时同时保留并说明用途。
4. 结论变化时增加新记录，不静默删除旧结论。
5. 实测中确认有效的命令同步维护在“常用命令速查”，失效命令应及时修订并说明替代方式。
6. 后续底盘、深度相机、电池和计算平台均在本文档新增独立章节。
