## 当前唯一下一步

**按手册第 20 节分阶段复测：先用日常 Smac 2D 入口保留基线证据，再验收自适应短倒车、双向转向和 3 Hz 更新；这些通过后才分别对照 State Lattice 与 EKF。**

复测前需重新构建并停止旧底盘、定位与导航。先确认日常入口仍加载 `SmacPlanner2D`，再验收无障碍基线、左右突发障碍各 5 次、后方有限空间和完全封路，记录成功率、方向反转次数、倒车距离、恢复耗时、最小净空和计算延迟。Lattice 对照不得同时混入 EKF；EKF 对照不得同时更换规划器。完整命令见[手册第 20 节](操作手册.md#20-nav-012-r8持续录包自适应恢复state-lattice-与-ekf-对照)。

2026-09-21 已复核用户提出的“近障碍时继续转向，由全局路径围绕障碍规划”意见：方向合理，但恢复 `ControlledSpin` 的 90°/10 s 上限暂不放宽。该上限不约束正常 DWB 连续弧线；障碍距车体过近时，约 0.19 m 的矩形包络旋转扫掠本身可能碰撞。下一轮先用 RViz 同时观察全局路径、局部路径与车体包络，区分“全局路径仍回到障碍”和“全局路径正确但局部无可行轨迹”，再决定调整规划代价、局部控制或恢复顺序。本次评审没有修改导航代码和参数。

2026-09-21 已确认后续固定采用 Hao 六终端开发方式：1～5 号终端通过免密别名 `ssh jetson` 登录 Jetson，6 号终端留在 Hao 本机运行轻量 RViz；实体车模用解引用后的本地覆盖目录。别名与直接 IP 均已通过 `BatchMode=yes` 验证。完整启动命令见[操作手册第 19.8 节](操作手册.md#198-日常六终端开发与导航复测2026-09-20-实测入口)，SSH 安装与回滚见第 19.9 节。

## 不确定事项

- D435 绝对深度、高帧率长时稳定性；Jetson 仍有 UVC `-32/-71`
- 麦轮重载地面上 DWB/平滑器加减速与静摩擦起步
- AMCL 在重复结构中的端点阈值、粒子离散度、恢复成功率尚无实机统计
- DWB 路径/目标项与障碍项量纲不同，须结合 `/evaluation`，不能只看参数数字
