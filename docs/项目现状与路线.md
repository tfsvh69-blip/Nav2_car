## 目标

完成四轮麦克纳姆小车的室内建图、定位与多点巡检；D435 同时作为实验性深度避障和后续回充近场视觉。当前仍先完成 Nav2 差速单点导航复测，保持纯轮式里程计；深度链路只完成离线资产，不越过基础导航和相机稳定性验收。长期产品分支的优先级与算法对照见 [工业级优化建议与学习路线](工业级优化建议与学习路线.md)。

**当前静止相机专项：**静止输入确实进入 Nav2 VoxelLayer 并生成二维规划代价。中央 R6、右侧 R10、左侧 R11 在障碍物在场时均稳定标记；健康有效的左右样本在盒子移走后约 1.1～1.34 s 恢复全空，左右桌椅观察带没有整体清空。左侧 3D VoxelGrid 仍比 2D Costmap 多留约 7.14 s；这是内部三维残留计时，未延迟本次二维地图通行空间恢复。该结论仅覆盖静止低盒和所测观察区。右/左各只有一次健康有效现场样本，左侧 R8 因健康超时作废；正式三轮验收和高箱场景未完成。当前先暂停额外摆盒；用户提出先通过 Hao 主机 RViz 直观看 Jetson 上这条静止链路的实际显示。该画面复核仍使用独立 B 诊断 Costmap，不等于正式 Nav2 或真实 `local_costmap` 集成。随后才考虑在车轮动力隔离时验证实验导航的真实 `local_costmap`，再另行设计移动避障安全试验。`navigation_depth_experimental.launch.xml` 和 `nav2_depth_experimental.yaml` 仅为实验配置，正式 Nav2 配置保持原样，移动深度避障未通过。

当前低盒侧向静止方法验证先停在这里：每侧已有一次健康有效样本，足以证明 D435 点云能让独立 Nav2 Costmap 标记低盒并在移走后清空二维障碍区；尚不足以完成每侧三轮重复、覆盖高箱或批准正式配置。2026-10-01 已完成一次实时查看，下一步优先定位本轮点云新鲜度异常，再在健康静止输入下核对右前蓝点、黄点与对应二维格值；当前不扩大到移动导航。完整本机 RViz 命令见[操作手册第 19.11 节](操作手册.md#1911-hao-查看静止深度-costmap)，B 参数与车上启动入口见[操作手册第 30.6 节](操作手册.md#306-原生裁剪候选静止现场复测仅离线四场景对照满足门槛后)，相机启动和停止顺序见第 30.2、30.4 节。这一步不摆盒、不启动正式导航、定位或底盘，也不改正式 Nav2 参数。只有真实地图静止验证通过，才计划单独的低速移动碰撞/绕障验收。Nav2 的二维 costmap 是规划/碰撞判断界面，三维 voxel 输出另作传感器几何诊断；本项目已把二维全区恢复空场基线作为主要静止清障判据，约 2 s 为目标，5 s 仍有新增二维残留才判失败。三维体素的延迟归零继续保留为独立指标。
