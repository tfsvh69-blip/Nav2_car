# 项目现状与路线

最后更新：2026-09-10

## 目标

完成四轮麦克纳姆小车的室内建图、定位与多点巡检；D435 只服务后续回充近场视觉。当前推进 Nav2 差速单点导航与避障验证，保持纯轮式里程计。

| 纯轮式 Odom | 已完成基线验证。累计编码器 10 圈实测 M1=1319.2、M2=1317.9、M3=1319.2、M4=1319.2 count/rev（均为 +1 正计数）。地面前进 1 m 物理与 Odom 一致，原地 360° 自转角度闭合良好，静止 30 秒零漂移。`base.yaml` 已正式启用 Odom 与 TF，作为 SLAM 建图输入。 |

| 串口 | 控制板 `/dev/myserial -> /dev/ttyUSB1`，雷达 CP2102 -> `/dev/ttyUSB0`，均具备稳定路径，115200；三终端独立启动，互不冲突。 |
| 雷达 | RPLIDAR A1 在 Humble 可发布 `/scan`，当前有效范围 0.10～3.00 m，RViz 方向已与实物对应。 |

## 当前唯一下一步

**NAV-003：静态地图定位与低速单点导航现场实机验证**。
NAV-002 运动建图、回访一致性与地图保存已实机通过，离线 NAV-003 导航底座、参数解析与独立地图重载已验证完毕。下一阶段在现场实车执行分阶段验收：原地 AMCL 定位收敛与代价地图观测、1m 直线与 90° 转向短距离到点（容差 0.15 m / 10°）、旋转短角方向复核、行驶中取消目标停车、平滑器/底盘命令超时安全以及全路径障碍阻断停车，全程保持纯轮式里程计，不接入 IMU/EKF。

## 连续推进顺序

1. NAV-001（已通过）：纯轮式 Odom + RPLIDAR A1 + SLAM Toolbox 原地静止建图链路冒烟验证。
2. NAV-002（已通过）：短距离受控运动建图、回访闭合与地图保存评估。
3. **NAV-003（当前）**：基于静态地图的 AMCL 定位、DWB 差速单点导航、取消停车与障碍阻断现场验收。
4. 轮式里程计和基础导航稳定后，按需评估仅融合校准后 `angular_velocity.z` 的 EKF。
5. 巡检任务状态机与多点调度。
6. 最后接入 D435、AprilTag 和回充流程。

## 不确定事项

- D435 绝对深度精度、高帧率长时稳定性；Jetson 仍有 UVC `-32/-71` 日志。
- DWB 与速度平滑器在麦轮重载地面上的加减速（当前初始设为线 0.20 m/s²、角 0.40 rad/s²）实际响应与静摩擦起步特性。
