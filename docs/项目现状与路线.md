# 项目现状与路线

最后更新：2026-09-08

## 目标

完成四轮麦克纳姆小车的室内建图、定位与多点巡检；D435 只服务后续回充近场视觉。当前不启动 Nav2，先闭环底盘和纯轮式里程计。

## 已确认

| 模块 | 关键结论 |
|---|---|
| 底盘 | 四个麦克纳姆轮，轮径 60 mm，轮宽 31 mm，轴距 120 mm，轮距 185 mm。 |
| 底盘方案 | M2/M4 一体插头交换后端口顺序为 M1=左前、M2=左后、M3=右前、M4=右后；用户已把四路编码器 A/B 全部对调，并反馈 PID 与对应电机现已匹配、板载闭环可正常驱动。V3.6 映射补丁保留但不刷写。 |
| 串口 | 控制板 `/dev/myserial -> /dev/ttyUSB0`，115200；同时只允许一个进程打开。 |
| 雷达 | RPLIDAR A1 在 Humble 可发布 `/scan`，当前有效范围 0.10～3.00 m，RViz 方向已与实物对应。 |
| D435 | 低负载 RGB+深度画面已经用户目视通过；实物倒装，安装 roll=`pi`。 |
| 整车模型 | 外廓 235×216×230 mm，雷达与 D435 位置已回填 URDF；IMU 轴向还未定线。 |

## 当前唯一下一步

用户已确认板载 PID 与电机闭环对应问题解决，`Kp=8.0, Ki=1.2, Kd=0.8` 已写入 Flash。现在进入 ODOM-001：先在四轮架空、零输出条件下测量每轮输出轴 10 圈的带符号累计编码器增量；实测值写入 Odom 配置后，依次验收前进 1 m、横移 1 m、逆时针 360° 与静止 30 秒漂移。完整命令只维护在[操作手册第 1.8 节](操作手册.md#18-纯轮式编码器-odom-首次标定odom-001)。

## 连续推进顺序

1. 测定四轮输出轴每圈编码计数和原始计数正负号；以轮径、轮距、轴距和累计编码器实现纯轮式 `odom -> base_footprint`。
2. 标定直行 1 m、横移 1 m、旋转 360°，并验收静止漂移。
3. 用雷达完成 2D 建图、定位和 Nav2 单点导航。
4. 在轮式里程计稳定后，再验证 IMU `gyro_z` 并评估融合。
5. 最后接入 D435 的 `realsense-ros`、AprilTag 和回充流程。

## 不确定事项

- 四轮输出轴 `count/rev`、原始计数方向，以及前进/横移/旋转的里程精度。
- IMU 的完整轴向、零偏与加速度标定。
- D435 绝对深度精度、高帧率长时稳定性；Jetson 仍有 UVC `-32/-71` 日志。
