## 待确认

1. 四轮每圈编码计数、原始计数正负号、地面距离/旋转标定。
2. MOTOR-017 逐轮 50% PWM 正转的完整观察记录（非 Odom 启动前置项；10 圈计数会同时给出 Odom 所需方向）。
3. IMU 轴向、零偏和加速度标定。
4. D435 的绝对深度精度、高帧率长时稳定性。Jetson 原生 UVC 仍有 `-32/-71` 日志，暂不将其当作高负载通过。
5. 电池化学类型、容量、充电判据与低电阈值。

### 2026-09-08 软件映射架空验收

- 用户确认四轮均按预期方向转动并可停止。前进的原始编码器符号稳定为 `[-,+,-,+]`，按已确认端口符号换算后四轮均为车轮前进方向；左横移换算后为 `[-,-,+,+]`，符合当前轮位映射。
