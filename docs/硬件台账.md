## 七、当前硬件阶段结论

1. CH341 能够识别 CH340，并稳定创建 `/dev/ttyUSB0`。
2. `/dev/myserial` 绑定已可供 ROS 节点使用。
3. M1～M4 轮位已确认为左前、右后、右前、左后；期望正转的端口符号为
   `[+1, -1, +1, -1]`。
4. 四路驱动输出、逐路 3 秒停车及 M1～M4 独立编码反馈均已确认；不再安排重复逐轮
   实验，下一次合并验证前进、横移、旋转、编码器符号和停车。
5. 雷达与底层板同时连接时，当前雷达是 `/dev/ttyUSB1`，底层板是 `/dev/ttyUSB0`；正式命令分别使用各自稳定别名。
6. Humble 雷达链路和 0.10～3.00 m 当前稳定读取已确认，剩余重点是安装 TF 与点云实际方向。
7. 控制板电压读取可用于后续 Web 状态和低电策略，但百分比与充电成功判据尚未标定。

## 八、当前待确认清单

5. D435/D435i 子型号、是否已到货和安装方式。
6. 电池类型、串数、容量、满电/低电阈值、充电桩和充电状态检测方式。
