## 五、当前硬件阶段结论

1. CH341 能够识别 CH340，并稳定创建 `/dev/ttyUSB0`。
2. `/dev/myserial` 绑定已可供 ROS 节点使用。
3. 当前只允许进行 M1、M2 架空低速点动测试。
4. 在确认电机位置、方向和编码器以前，不把两电机映射写入正式导航运动学配置。
