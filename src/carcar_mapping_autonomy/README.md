# 二维自主建图（实验入口）

C++任务监督、SLAM接纳/闭环诊断、固定explore_lite和原始激光Collision Monitor。网页通过 `/mapping/autonomy/request` 提交带 task_id/request_id 的操作，状态 `/mapping/autonomy/state` 是车端事实。请求受理不是动作完成或停车证明。

NAV-018-R16：发布者唯一性检查由`TopologyMonitor`独立线程执行，控制循环不等待同步图查询；结果超过1秒未更新或检查失败时按原健康故障链路停车，迟到结果不解锁FAULT。保持原发布者规则，轮询间隔为每次查询完成后500毫秒；底盘0.3秒超时、传感器新鲜度及限速／净空门槛保留。状态增加`control_tick_gap_ms`、`control_max_tick_gap_ms`、`control_max_tick_work_ms`、`topology_query_ms`、`topology_age_s`，均为软件耗时而非物理速度。注入400毫秒延迟的真实监督器测试由约451毫秒断流变为约50毫秒连续输出；过期查询仍锁停。注入库仅BUILD_TESTING使用，不安装或用于实车。原Python底盘计时／编码器恢复的授权、离线验证和现场待验边界见[测试记录R16](../../docs/测试记录.md#nav-018-r16)。

NAV-018-R14（2026-10-29）：观测点增加静态可达性筛选。`ObservationSelector`在独立计算线程中复用原规划掩膜及三格起步余量规则，从当前map车位计算八邻接连通区域，只在该区域中寻找前沿0.8米内满足原净空／视线／任务范围的观测点。地图内容版本不变时缓存掩膜，起点格改变时重算连通区域；结果必须与当前操作编号、任务代次、地图版本及起点格匹配。暂停／闭环／新图不能让迟到结果重新开车。筛选期间`goal_selecting=true`、`goal=null`，没有实际观测点时日志也记录`target=null`，网页说明尚未预检／下发并保留暂停入口。原Smac规划、路线审查、动态碰撞保护、速度与预算不变。筛选不承诺动态可达或覆盖完成；实车起步等待的改善仍须重新计时。离线回放工具仅在BUILD_TESTING中构建，不初始化ROS或接触活动录包，完整命令见[手册39.9](../../docs/操作手册.md#399-观测点可达性离线回归nav-018-r14)。

监督器仅在筛选拒绝且尚未提交任何规划的情况下，在`/mapping/explore_candidate_rejection`发布对应proxy UUID（`std_msgs/String`，Reliable/Volatile/depth 10）；暂停、健康故障、规划或执行失败不发此事件。探索器显式配置`candidate_rejection_topic`后，须同时收到匹配UUID的拒绝事件和ABORTED终态，才安排一次100毫秒定时重选；两个话题先后到达均可，禁止递归或抢占。活动目标、普通失败、成功等待新图、1Hz周期检查及两次失败／60秒冷却保持；暂停取消定时器，全部候选暂避后回到正常周期。消息记忆最多64个UUID。未配置该话题的其他探索入口保持原行为。

固定预算20m/2400s、返程600s，自动0.10m/s与0.36rad/s。地图和质量门槛未实机通过，不宣称可无人交付。完整构建、启动、观察、停止和恢复见[手册39节](../../docs/操作手册.md#nav-018-operation)。旧地图不编辑，候选审核后正式发布并单独启用。原实验资产保留。

NAV-018-R10净空检查使用真实亚格车位到占用／未知方格最近点，精确判定0.22m圆包络相交；先取整到格心会同时造成误拒绝与漏碰撞，现场反例及两类失败回归均保留。规划附加余量不改，Smac起点格心若仍不满足原净空，不声称退离已打通，也不放开危险格心。实车目标到达与完整场地覆盖分别验收。

Speckle仅Distance，默认0.10m相邻距离、2束窗口是实验候选，必须与原始输入比较细腿保留/误占用/延迟，不能只凭点变少转正。当前3m/5cm/原损失保持，IMU不融合。原始scan不被覆盖，过滤NaN不视为空闲射线。

NAV-018-R5完整待命启动回归中，DWB近距离返程曾停滞，Rotation Shim对照也未通过，失败证据保留。新实验组合用独立`controller_rpp.yaml`覆盖控制器，复用本机Nav2 1.1.20的Regulated Pure Pursuit（Apache-2.0），不安装或升级系统包；原`nav2_mapping.yaml`和普通导航／巡检DWB入口保留。RPP沿路径几何计算速度，转向、跟随及近终点调向由官方插件处理，平滑器及最终监督器仍限制0.10m/s／0.36rad/s，禁止倒车，碰撞与未知区域门槛不变。软件房间结果不能作为本车转弯／制动验收。

新增真实浏览器完整待命生命周期回归在`carcar_inspection/web/test/mapping-start-lifecycle.mjs`，包含真实HTTP、prepare、SLAM／Nav2进程启动、两轮暂停／接管／恢复／返程／保存／结束／再启动，无Mock响应；每轮还必须从独立轮式反馈确认至少0.15米模拟平移，静止补帧的扫描序号增长不能代替行驶。完整执行与停止说明仍只维护手册39节。监督器首个编码器样本前不以默认零坐标作位移基准，保留真实移动后无扫描接纳的锁停。

静止起步默认在首帧后再接纳最多3帧，间隔沿用`minimum_time_interval`，2秒内结束。这几帧临时把Karto的`MinimumTimeInterval`设为0并立即恢复；0.10米移动门槛和足迹拒绝保持。`startup_extras`只计补帧次数。实车起点未知格是否补齐仍要现场看。

NAV-018-R10：地图扩边改为独立线程检查固定目标及剩余路径，安全时保持同一目标；闭环／净空失效取消停稳后重验同一观测点。使用本机Nav2 Humble 1.1.20 `KeepoutFilter`，独立C++ `mapping_known_space`把既有0.22米净空条件发布为规划禁行掩膜（`/mapping/known_space_mask`及`/mapping/known_space_filter_info`，Reliable/Transient Local/depth 1），原SLAM地图与足迹不改。Humble插件不支持旋转网格，掩膜拒绝非零网格yaw；当前SLAM地图为零yaw。无新增系统安装，替代方案及许可证见[诊断记录](../../docs/archive/2026-10-28-自动建图切点诊断/README.md)。

`/mapping/autonomy/state`新增 `frontier_goal`、`observation_goal`、`goal_id`（探索proxy UUID）、`nav_goal_id`（内部导航UUID）、`navigation_attempt`、`map_revision`（几何或栅格内容变化）、`map_sequence`（接收次数）、`goal_change_reason`及`goal_revalidating`。现有`goal`仍表示实际观测点。内部重验保持proxy UUID，通过后内部导航UUID变化；普通安全扩图两者都保持。取消不再伪报规划／控制失败。

探索候选参数：`progress_timeout=30.0`、`progress_epsilon=0.10`、`region_radius=0.40`、`region_cooldown=60.0`，同区失败2次暂避，最多64区。暂停恢复保留记忆，新任务节点重启重置；成功后等待新图。全部候选暂避保持未完成，不将其视为探索结束。完整走廊测试入口、运行结果与实机未确认项以手册及测试记录为准。

栅格连续性补充（R10）：仅检查路径采样点会漏掉点间擦入未知格的情况，已用实际走廊曲线复现。规划掩膜与观测点额外预留 `sqrt(2) × map_resolution`（5厘米栅格约7.1厘米）；最终路线审查仍为0.22米并按半格插值。该余量属于实验规划约束，不是实物车身尺寸或SLAM填白。对应 `PlanningMask.GridDiagonalCannotCutAcrossUnknownFootprint` 回归。

Humble生命周期兼容入口`mapping_lifecycle_manager`继续实例化官方管理器和Bond；只在本可执行文件中将默认`LifecycleServiceClient::change_state(uint8_t)`定义为5秒应答等待、超时后2秒真实状态核对。达到明确期望状态才继续，否则拒绝；正常应答必须success，不盲目重发。精确锁定Nav2 1.1.20，其他入口及系统库不改。`transition_response_timeout`仅控制生命周期应答（候选默认5秒），不扩大运动许可、数据新鲜度或取消停车期限。详见诊断记录中的上游6556对照和丢应答回归。

正常运动补充：Humble外层节流与Karto的0.10米门槛可能错开。适配器在相对最后真实接纳的里程计达到原距离／角度与时间条件后，限频重试原Karto入口；原匹配、移动门槛、静止补帧上限及接纳锁停均保留。`admission_retries`只计尝试，不代表已入图；新增真实SLAM的0.095→0.105米分步回归锁住该缺口。

观测点还须与原始前沿视线连通：DDA逐格检查，中间未知或占用拒绝，前沿终格可未知，避免把墙另一侧的自由点当作有效观测点。起步观测点距车不超过0.25米拒绝，由探索器继续尝试同簇其他点。

建图专用行为树对周期规划失败延迟400毫秒、仅重试一次同一目标；延迟不是收到新地图的证明。持续失败仍结束，FollowPath失败不自动恢复。不调用清图／Spin／BackUp／Wait，其他入口保持原树。

当前实验RPP内部`max_angular_accel=3.20`恢复Humble默认可行速度约束，最终平滑器仍限0.80rad/s²及0.36rad/s，线速0.10m/s不变。原内部0.80可能与实测角速度限幅叠加，导致转向命令一直偏小；合成死区回归及一次实车6个探索目标／返程已验证，用户确认转向连续、返回起点附近。它仍是实验候选，完整覆盖／重复性继续单独验收，旧0.80及失败证据保留。Nav2跨目标反馈还可能短暂带旧正距离；监督器按固定观测点的直线下界加0.25米候选余量检查，明显偏短者不转发探索器，防止污染无进展基准。
