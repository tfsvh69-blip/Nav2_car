正常运动补充：Humble外层节流与Karto的0.10米门槛可能错开。适配器在相对最后真实接纳的里程计达到原距离／角度与时间条件后，限频重试原Karto入口；原匹配、移动门槛、静止补帧上限及接纳锁停均保留。`admission_retries`只计尝试，不代表已入图；新增真实SLAM的0.095→0.105米分步回归锁住该缺口。

观测点还须与原始前沿视线连通：DDA逐格检查，中间未知或占用拒绝，前沿终格可未知，避免把墙另一侧的自由点当作有效观测点。起步观测点距车不超过0.25米拒绝，由探索器继续尝试同簇其他点。

建图专用行为树对周期规划失败延迟400毫秒、仅重试一次同一目标；延迟不是收到新地图的证明。持续失败仍结束，FollowPath失败不自动恢复。不调用清图／Spin／BackUp／Wait，其他入口保持原树。

当前实验RPP内部`max_angular_accel=3.20`恢复Humble默认可行速度约束，最终平滑器仍限0.80rad/s²及0.36rad/s，线速0.10m/s不变。原内部0.80可能与实测角速度限幅叠加，导致转向命令一直偏小；合成死区回归及一次实车6个探索目标／返程已验证，用户确认转向连续、返回起点附近。它仍是实验候选，完整覆盖／重复性继续单独验收，旧0.80及失败证据保留。Nav2跨目标反馈还可能短暂带旧正距离；监督器按固定观测点的直线下界加0.25米候选余量检查，明显偏短者不转发探索器，防止污染无进展基准。
