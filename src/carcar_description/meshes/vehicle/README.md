接入时保留原 STL 坐标，不重新写网格：

- 顶部总结构、雷达底板和 Jetson 下置底板通过绕 X 轴旋转 `+90°`，把原 STL 的 Y
  厚度方向映射为车体 Z。
- 两个橙色锁底板零件当前均使用 `rpy=(90°,0°,0°)`；前端零件按 2026-09-24 用户圈注，
  在先前位置绕车体 Z 轴翻转 180°，同时调整其 URDF 原点以保留平面中心。
  后端零件的变换未随该次圈注改变。原始 STL 的
  `Y=0` 带孔平底贴住离地 135 mm 的蓝色顶板、两个螺孔沿车体 Y 轴排列；其竖边分别
  靠在舵机盒前后端，作为不随轴转动的固定件。前端零件靠近顶板前缘，孔中心在板内，
  外侧约 2 mm 伸出板的近似视觉模型仍待实物确认。两件固定脚以固定关节独立连接到
  `camera_mount_link`，避免 RViz 把橙色网格显示成舵机壳的粉色。
  当前 `camera_servo_left_foot_joint`（后侧）的 `camera_mount_link` 原点为
  `(-0.038,0.015392723,-0.010) m`，`camera_servo_right_foot_joint`（前侧）为
  `(0.012,0.015392723,-0.010) m`；二者旋转均为 `(90°,0°,0°)`。这些是网格安装变换，
  螺孔与顶板孔位的实物偏差仍待量测。
- 黑色相机支架使用 `rpy=(0°,0°,0°)`，原 STL 小端轴孔位于可动的
  `camera_tilt_link` 转轴，大平面朝向相机背面。
- 旧蓝色相机底部/直接支架 STL 作为历史资产保留，不再进入当前 URDF。
- 新增件的安装位姿来自外廓、实车照片和用户粗量轴心，仍需在 RViz 与实物
  并排检查车头方向和左右镜像。

顶板 STL 长度为 218 mm，与尺量 220 mm 有 2 mm 差异；视觉保留原网格尺寸，碰撞体按
尺量 220 mm。车体网格后边界仍沿用旧模型的 -105 mm 初值；新相机在平视时的左红外光心
粗量为 x=150 mm，旧 235 mm 整车长不再代表当前扫掠包络。雷达底板暂对齐原后边界。
STL 支架均使用所属 link 的简化碰撞体或车体包络；并未为每个镂空、螺孔建立精细碰撞模型。
