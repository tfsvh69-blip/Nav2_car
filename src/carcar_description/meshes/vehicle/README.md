接入时保留原 STL 坐标，不重新写网格：

- 顶部总结构、雷达底板和 Jetson 下置底板通过绕 X 轴旋转 `+90°`，把原 STL 的 Y
  厚度方向映射为车体 Z。
- 相机底部支架使用 `rpy=(90°,0°,90°)`，原 X/Y/Z 分别对应车体 +Y/+Z/+X。
- 相机直接支架使用 `rpy=(90°,0°,180°)`，封闭安装端朝相机后壳，长臂沿 -X 延伸。
- 上述安装变换来自外廓、实车照片和用户实测传感器中心联合约束；最终仍需在 RViz 与实物
  并排检查车头方向和左右镜像。

顶板 STL 长度为 218 mm，与尺量 220 mm 有 2 mm 差异；视觉保留原网格尺寸，碰撞体按
尺量 220 mm。纵向位置暂假定左红外所在镜头面是最前端，由 `130-235=-105 mm` 反推
后边界；这不是后边界的独立实测值。雷达底板暂对齐该后边界，传感器 TF 采用实测值。
STL 支架均使用所属 link 的简化碰撞体或车体包络；并未为每个镂空、螺孔建立精细碰撞模型。
