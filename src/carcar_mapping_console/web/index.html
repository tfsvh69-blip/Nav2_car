图层与地图说明

激光与轮式里程计生成俯视地图，使用 map 坐标系：黑色为占用、白色为空闲、灰色为未知；红点为当前激光，蓝色为估计车位示意（非车身外廓），黄色为人工初始位置。默认 绿色虚线圆为本次自动探索边界，绿色方框为返程起点，紫色圆为当前导航目标。橙色细框是车身停车框，0.28×0.26米。紫色是全局代价，橙色色块是局部代价，青色是全局路径，黄色是控制器正在跟随的路径，橙线是纯追踪的碰撞预测弧。代价里的红色是高代价障碍，透明处是未知或零代价，不能据此认为一定能过。默认 5 厘米/格；缩放只改变显示比例，地图约 3 秒更新。白色不保证各高度均无障碍。RGB 是前方透视辅助图，640 × 480 为像素数；窗口大小不改变镜头视场，不能与俯视地图逐像素比较。
