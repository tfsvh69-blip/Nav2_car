# carcar 四轮麦克纳姆导航巡检小车

ROS 2 Humble / Ubuntu 22.04项目。平板随行建图支持网页待命、新建／续建、摇杆遥控、成对保存和结束任务；RGB为可选辅助，地图使用激光＋纯轮式里程计。10月20日用户反馈可正常建图，弱特征形变专项、停车距离、重启自启及完整深度导航仍待验收；当前运行状态与下一步以项目路线和测试记录为准。

NAV-018新增手动／自动建图、纯激光去噪与质量监督、候选审核／发布／启用链路；新入口保持实验状态，深度不参与本阶段导航。完整启动、观察、停止及恢复统一见[操作手册39节](docs/操作手册.md#nav-018-operation)，验证边界见[实施记录](docs/archive/2026-10-27-自动建图实施/README.md)。

长期目标是单层巡检：导航时固定相机角度，停车后俯仰拍RGB、本地保存并排队上传。第一版不做门状态或危险识别；[巡检应用](src/carcar_inspection/README.md)已有网页示教、单点导航、车端任务、最终停车和上传队列实现，完整巡检尚未实机验收。上传接收端未部署，`upload_url`默认留空，当前照片在网页查看／下载。

2026-10-25起按“链路讲解→代码→观察／测试→结论”推进，首轮提取建图状态后台查询。入口分类和唯一下一步见[项目路线](docs/项目现状与路线.md)，原理与实测对照见[学习路线6.3](docs/工业级优化建议与学习路线.md#63-按真实代码理解四条链路)。
