# carcar 四轮麦克纳姆导航巡检小车

ROS 2 Humble / Ubuntu 22.04项目。当前使用小泽WiFi覆盖内的平板随行建图：开机自动登录后网页待命，平板新建/续建、摇杆遥控、成对保存和结束任务；RGB为可选辅助，地图使用激光＋纯轮式里程计。相机到平板短时通路已有现场确认；新流程触控、真实场地建图、停车距离、重启自启及完整深度导航仍待验收。

长期目标是单层巡检：导航时固定相机角度，停车后俯仰拍RGB、本地保存并排队上传。第一版不做门状态或危险识别；[巡检应用](src/carcar_inspection/README.md)已新增网页点位示教、固定单角度采集、车端任务与最终停车代码，APP-001-R1先离线验证、默认配置模式，尚未实机验收，云端协议与上传程序待实现。
